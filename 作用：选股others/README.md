# 股票选股扫描器

基于技术指标的A股选股工具，支持多维度扫描和TD序列分析。

## 功能特点

### 1. 综合选股扫描器 (`run_scan.py`)
- **实时数据抓取**：无需缓存，每次都获取最新数据
- **自动保存**：数据自动保存为CSV格式到 `./data` 目录
- **多指标组合**：支持多种技术指标组合筛选
- **全市场扫描**：支持全市场或自定义股票池

### 2. TD序列扫描器 (`run_td_scan.py`)
- **多周期分析**：支持日K、周K、月K三个周期
- **TD序列检测**：自动识别9底、8底、7底
- **独立结果**：每个周期独立输出，方便对比
- **灵活筛选**：可设置最小TD计数阈值

## 技术指标说明

### 综合选股指标

| 指标 | 说明 | 用途 |
|------|------|------|
| 均线金叉 | 5日均线上穿20日均线 | 短期趋势转强 |
| MACD金叉 | MACD快线上穿慢线 | 动能转强 |
| MACD零轴下金叉 | 零轴下方的MACD金叉 | 更可靠的买入信号 |
| RSI超卖拐头 | RSI低于30后拐头向上 | 超卖反弹 |
| 放量突破 | 放量突破前期阻力位 | 上涨启动 |
| TD序列 | TD买入计数 | 连续下跌后的反弹信号 |

### TD序列指标

| 级别 | 说明 | 可靠性 |
|------|------|--------|
| 9底 | TD买入序列达到9 | 最强买入信号 |
| 8底 | TD买入序列达到8及以上 | 较强买入信号 |
| 7底 | TD买入序列达到7及以上 | 潜在买入信号 |

## 使用方法

### 一、综合选股扫描器

#### 1. 测试模式（推荐新手）

扫描前N只股票，快速测试功能：

```bash
# 扫描前300只股票（默认）
python run_scan.py --mode test

# 扫描前100只股票
python run_scan.py --mode test --n 100

# 设置最少信号数为3
python run_scan.py --mode test --n 300 --min-signals 3
```

#### 2. 全市场扫描

扫描整个A股市场：

```bash
# 全市场扫描（最少2个信号）
python run_scan.py --mode full

# 提高筛选标准（最少3个信号）
python run_scan.py --mode full --min-signals 3
```

#### 3. 自定义股票池

扫描指定的股票列表：

```bash
# 扫描指定股票
python run_scan.py --mode custom --stocks 000001 000002 600000

# 设置筛选条件
python run_scan.py --mode custom --stocks 000001 000002 600000 --min-signals 1
```

### 二、TD序列扫描器

#### 1. 测试模式

```bash
# 扫描前300只股票（所有周期）
python run_td_scan.py --mode test --n 300

# 只分析日K和周K
python run_td_scan.py --mode test --n 300 --periods daily weekly

# 只分析9底（最严格）
python run_td_scan.py --mode test --n 300 --min-td 9

# 分析周K的8底及以上
python run_td_scan.py --mode test --n 300 --periods weekly --min-td 8
```

#### 2. 全市场扫描

```bash
# 扫描全市场（所有周期，7底及以上）
python run_td_scan.py --mode full

# 只扫描日K的9底
python run_td_scan.py --mode full --periods daily --min-td 9

# 扫描周K和月K
python run_td_scan.py --mode full --periods weekly monthly
```

#### 3. 自定义股票池

```bash
# 扫描指定股票
python run_td_scan.py --mode custom --stocks 000001 000002 600000

# 只分析日K
python run_td_scan.py --mode custom --stocks 000001 000002 --periods daily
```

## 参数说明

### 综合选股扫描器参数

| 参数 | 说明 | 默认值 | 可选值 |
|------|------|--------|--------|
| --mode | 扫描模式 | test | full, test, custom |
| --n | 测试模式扫描数量 | 300 | 任意正整数 |
| --min-signals | 最少信号数量 | 2 | 1-5 |
| --stocks | 自定义股票代码列表 | - | 如: 000001 000002 |

### TD序列扫描器参数

| 参数 | 说明 | 默认值 | 可选值 |
|------|------|--------|--------|
| --mode | 扫描模式 | test | full, test, custom |
| --n | 测试模式扫描数量 | 300 | 任意正整数 |
| --min-td | 最小TD计数 | 7 | 7, 8, 9 |
| --periods | 分析周期 | 全部 | daily, weekly, monthly |
| --stocks | 自定义股票代码列表 | - | 如: 000001 000002 |

## 注意事项

1. **数据实时性**：系统每次都从网络实时获取数据，确保数据最新
2. **请求频率**：为避免被限制，代码已内置请求间隔（0.1秒）
3. **网络问题**：如果获取失败会自动重试3次
4. **数据保存**：所有数据自动保存，方便离线分析
5. **文件覆盖**：每次运行会生成新文件（带时间戳），不会覆盖旧文件
6. **内存占用**：全市场扫描会占用较多内存，建议分批处理

## 常见问题

### Q1: 为什么有些股票数据获取失败？
A: 可能原因：
- 股票停牌
- 网络连接问题
- API限制（会自动重试）

### Q2: 如何提高扫描速度？
A:
- 使用测试模式扫描部分股票
- 减少分析的周期（只分析日K）
- 使用更快的网络连接

### Q3: TD计数是什么意思？
A: TD序列是一个技术指标，用于识别连续下跌后的潜在反弹点：
- 7底：连续7根K线收盘价低于4根前
- 8底：连续8根
- 9底：连续9根（最完整的信号）

### Q4: 如何筛选结果？
A: 打开Excel文件后，可以使用：
- 筛选功能按信号数筛选
- 排序功能按涨跌幅排序
- 条件格式高亮显示特定条件

### Q5: 信号出现后是否立即买入？
A: 不建议。技术指标仅供参考，还需要考虑：
- 大盘环境
- 个股基本面
- 止损策略
- 仓位管理

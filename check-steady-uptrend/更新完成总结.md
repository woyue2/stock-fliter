## 🎓 技术细节

### 小跌阈值：1.64%

**原理**：
- 基于统计学 1σ（一个标准差）
- 正态分布中约68%数据在 ±1σ 范围内
- 可过滤大部分噪音波动

**调整方法**：
修改 `mystic_indicators_tolerant.py`：
```python
DEFAULT_SMALL_DROP_THRESHOLD = 1.64  # 改为你想要的值
```

### 有效上涨判断

```python
if close >= open:
    return True  # 真涨或平
else:
    drop_pct = (open - close) / open * 100
    if drop_pct < 1.64:
        return True  # 小跌，视为有效上涨
    else:
        return False  # 大跌
```

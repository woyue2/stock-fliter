## 1. 核心判定逻辑

**计算公式：**
`主力强度 = (主力净额 / 总成交额) * 100`

**判定标准：**
| 阶段 | 主力强度范围 | 典型特征 |
| :--- | :--- | :--- |
| **1. 建仓** | $1 < 强度 < 3$ | 主力缓慢吸筹 |
| **2. 抢筹** | $强度 \ge 3$ | 资金大幅流入，爆发力强 |
| **3. 洗盘** | $-1 \le 强度 \le 1$ | 震荡蓄势，剔除浮筹 |
| **4. 出货** | $强度 \le -1$ | 资金流出，风险加大 |

## 3. 研究方向建议

1.  **自动化计算**：在 `get-data` 模块中，尝试获取板块的“主力净额”和“成交额”，自动计算“主力强度”。
2.  **背离研究**：观察“散户净额”持续为负且“主力强度”提升的板块，通常具有更强的爆发力。
3.  **预期回测**：对“冲高回落”和“上涨”的预期进行历史数据验证，看是否能转化成卖出/买入信号。

# 策略逻辑矩阵：资金容量 × 资金纯度 × 资金效率 (A*B*C 模型)

> **目标**：通过衡量“主力攻击意愿”、“市场散户接盘(背离)情绪”与“拉升效率/容量”，来预测板块短期（次日或1周内）的走势。

## 1. 核心计算公式 (基础变量)

*   **[A] 主力强度** = `(主力净额 / 总成交额) * 100`
    *   *判定基准*：`> 3` 抢筹，`1~3` 建仓，`-1~1` 洗盘，`< -1` 出货。
*   **[B] 散户反向背离** = `散户净额 < 0 且 主力买入` 或 `散户净额 > 0 且 主力卖出`
    *   *判定基准*：异向即为“真行为”（主力真建仓/洗盘），同向即为“假行为”（诱多或假摔）。
*   **[C1] 资金拉升效率** = `涨幅 / 主力强度`
    *   *判定基准*：衡量1点强度能换取多少涨幅。数值极低说明拉升吃力或存在“对倒”。
*   **[C2] 资金承接容量** = `板块总成交额`
    *   *判定基准*：数值过低（中小盘极易被操控诱多），数值过高（盘子巨大难封板拉升）。

## 2. 预测结果演算方程 (判定条件逻辑树)

基于上述单项基础变量，多重叠加判定板块未来行情的规则方程如下：

### 📈 【强烈看涨预期 (上涨)】
> 满足以下任一公式序列，视为极具操作价值的“真金白银博弈介入点”。

*   **公式 1：完美抢筹/建仓**
    *   `IF` **[A] 强度** > 1.0
    *   `AND` **[B] 反向背离** == True (即散户恐慌交出筹码，净额 < 0)
    *   `AND` **当前涨幅** < 3.0% (未透支拉升空间)
    *   `THEN` ➡️ **预期上涨** 
    *   *(代表案例：固态电池、可控核聚变 — 主力花真钱在扫低位货)*

*   **公式 2：正常洗盘待拉升**
    *   `IF`  -1.0 ≤ **[A] 强度** ≤ 1.0 (缩量横盘)
    *   `AND` **[B] 反向背离** == True (即散户忍受不了正在抛售，净额 < 0)
    *   `AND` **[C2] 容量** > 300 (非无人问津的冷门板块)
    *   `THEN` ➡️ **预期上涨** 
    *   *(代表案例：卫星导航、军工 — 主力洗人收筹)*

*   **公式 3：恐慌错杀反弹**
    *   `IF`  **[A] 强度** < -1.0 (看似出货)
    *   `AND` **散户净额** < 0 (散户恐慌杀跌比主力更猛)
    *   `THEN` ➡️ **预期上涨** 
    *   *(代表案例：油气采服 — 极端情绪释放后的物极必反反抽)*


### ⚠️ 【高位套人预警 (冲高回落)】
> 虽然理论看涨或主力试图做多，但受制于盘面环境跟客观阻力，大概率会半路夭折。

*   **公式 4：白马巨无霸的钝化**
    *   `IF` **[A] 强度** < 1.0
    *   `AND` **[C2] 容量** > 8000 
    *   `THEN` ➡️ **预期冲高回落** 
    *   *(代表案例：上证指数 — 即使真洗盘，盘面沉淀筹码太多，拉不动即回落)*

*   **公式 5：跟风盘涌入的洗盘需求**
    *   `IF` **[A] 强度** > 1.0 (哪怕是建仓或抢筹区)
    *   `AND` **[B] 反向背离** == False (散户也在同向大量涌入买入，净额 > 0)
    *   `THEN` ➡️ **预期冲高回落** 
    *   *(代表案例：电力 — 主力绝对不会帮散户抬轿，大概率骗跟风盘后反手下杀)*

*   **公式 6：空间严重透支**
    *   `IF` 满足“真抢筹”等看涨条件
    *   `AND` **当前涨幅** > 5.0%
    *   `THEN` ➡️ **预期冲高回落** 
    *   *(先手获利盘已丰厚，随时准备核按键抛售锁定利润)*


### 📉 【绝命毒师陷阱 (下跌)】
> 切勿被指标数字蒙蔽，属于假动作或被资金彻底抛弃地带，触碰即回撤。

*   **公式 7：空转高位诱多（对倒套人）**
    *   `IF` **[A] 强度** > 2.5 (表现为极其凶猛的资金抢筹假象)
    *   `AND` **[C1] 效率** < 0.3 (用极其巨量的买单，涨幅却像蜗牛)
    *   `AND` **[C2] 容量** < 500 (只有极小的资金盘面)
    *   `THEN` ➡️ **预期下跌** 
    *   *(代表案例：短剧游戏 — 经典的主力用自己双手倒自己右手的诱多陷阱，次日连杀)*

*   **公式 8：阴跌的死水**
    *   `IF` **[A] 强度** < 0.5 (主力死寂)
    *   `AND` **[C2] 容量** < 300 (无人关注)
    *   `THEN` ➡️ **预期下跌** 
    *   *(代表案例：文化传媒 — 连所谓的洗盘资金波澜都没有的纯边缘阴跌)*

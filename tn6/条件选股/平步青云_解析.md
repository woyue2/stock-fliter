# 平步青云策略解析报告

依据 `公式规则.md` 中的语法定义，对 `平步青云.md` 中的公式解读如下：

---

## 1. 变量定义与时间限制
*   **IK (中间赋值 `:=`)**：`IK := 1270101;`
    *   时间常量，代表 2027年1月1日。
*   **DRAWA (逻辑判断 `:=`)**：`DRAWA := DATE <= IK;`
    *   **时效性控制**：确保选股公式仅在 2027年1月1日之前有效。

## 2. 核心技术指标
该公式通过成交量、价格涨幅以及形态突破三个维度来筛选强势股。

### 2.1 条件 1：能量爆发 (倍量)
*   **代码**：`倍量 := V / REF(V, 1) >= 3;`
*   **解读**：今日成交量（`V`）是昨日成交量（`REF(V, 1)`）的 **3 倍或以上**。这代表资金在今日剧烈入场，属于极具爆发力的量能信号。

### 2.2 条件 2：形态质量 (非涨停大阳线)
*   **代码**：
    ```sql
    最高涨幅 := H < REF(C, 1) * 1.095 AND H > REF(C, 1) * 1.01;
    阳线 := C > O;
    条件2 := 最高涨幅 AND 阳线;
    ```
*   **解读**：
    1.  **拒绝封单**：今日最高价（`H`）小于昨日收盘价的 1.095 倍。这意味着该股今日**没有封死涨停**（通常是为了在形态上避开极致的抛压或者为了洗盘）。
    2.  **确保上涨**：涨幅必须大于 1% 且是阳线（`C > O`）。
    3.  **总结**：筛选出有主力大幅拉升但未直接封板的强力阳线。

### 2.3 条件 3：区间突破 (横盘突破)
*   **代码**：
    ```sql
    HIGH_N := HHV(H, N);  {N=5}
    条件3 := C >= HIGH_N AND REF(C, 1) < REF(HIGH_N, 1);
    ```
*   **解读**：
    1.  **寻找高点**：`HHV(H, 5)` 取最近 5 个交易日的最高点。
    2.  **瞬间破位**：今日收盘价（`C`）站上了这 5 天的最高点，而昨天（`REF`）还没站上去。
    3.  **总结**：这是一个标准的**短线箱体/平台突破**信号。

---

## 3. 指标输出：平步青云信号
*   **平步青云 (输出赋值 `:`)**：
    ```sql
    平步青云 : DRAWA AND 倍量 AND 条件2 AND 条件3;
    ```
*   **逻辑模型总结**：
    1.  **公式有效**（在截止日期内）。
    2.  **资金猛烈**（3 倍放量）。
    3.  **形态突破**（突破 5 日平台）。
    4.  **力度适中**（大阳线但未涨停，保留了持续进攻的可能性）。

---

## 4. 选股策略总结
此公式描述的是一种**“三倍量突破”**模型。
*   **核心逻辑**：寻找那些在低位或横盘震荡 5 天后，突然放出巨量（3 倍）向上突破的个股。且特意避开了直接涨停的个股，目的是寻找那些主力刚刚开始发力、形态较佳、且盘中给到了入场机会的强势品种。
*   **实战建议**：由于包含 3 倍量的极高能量要求，建议配合大环境（大盘量能）使用。若整体市场低迷，三倍量往往意味着“孤立爆发”，需警惕冲高回落；若市场活跃，则是极佳的超短线起跳点。

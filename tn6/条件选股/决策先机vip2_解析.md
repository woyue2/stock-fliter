# 决策先机vip2 策略解析报告

依据 `公式规则.md` 中的语法定义，对 `决策先机vip2.md` 中的公式解读如下：

---

## 1. 策略核心：换手板突破 + 爆量竞价
这是一个极高强度的短线选股模型，专门抓取昨日有表现、今日有巨量资金抢筹的“妖股候选人”。

## 2. 核心逻辑拆解

### 2.1 昨日基因筛选（昨日必须是“好板”）
*   **不超过3连板**：`不超过3连板 := 非一字板 AND NOT(大前日涨停);`
    *   **解读**：筛选昨日涨停的个股，但排除了一字板（必须要有换手）和已经连拉 4 板以上的高位股，寻找处于上升初期或中期的标的。
*   **60日高点突破**：`昨日收盘价 >= REF(HHV(HIGH, 60), 1);`
    *   **解读**：要求昨日收盘价站上过去 3 个月（60个交易日）的最高点。这意味着上方**没有任何套牢盘压力**，空气稀薄，利于拉升。

### 2.2 今日竞价条件（主力抢筹信号）
*   **高开空间**：`高开条件 := 开盘涨幅 >= 3 AND 开盘涨幅 <= 6;`
    *   **解读**：不选择平开或低开，也不选择过高开（高开 8%-9% 容易回落）。3%-6% 既体现了强势，又留出了盘中涨停的获利空间。
*   **竞价触及涨停**：`固定竞价最高价 >= 集合竞价涨停价 * 0.998;`
    *   **解读**：这证明在 9:15-9:25 的竞价过程中，曾经有大单直接挂涨停价试盘。这是主力**高度控盘或急于拿筹码**的铁证。

### 2.3 关键：竞昨日比 (爆量指标)
*   **代码**：`竞昨日比条件 := (固定竞价金额 / 昨日成交金额 * 100) >= 10;`
*   **解读**：这是全篇公式最牛的地方。**要求 9:25 分开盘这一瞬间的成交额，必须占据昨天全天成交额的 10% 以上。**
    *   如果昨天成交 1 亿，今天开盘就要成交 1000 万。这代表资金在今日开盘时表现出极其强烈的合力，是**真突破**的概率极高。

---

## 3. 选股策略总结
*   **逻辑模型**：换手首/二板 + 60日新高 + 今日3%-6%高开 + 竞价曾触板 + **开盘爆量(10%)**。
*   **使用建议**：
    1.  **无限期使用**：没有日期锁。
    2.  **超短线首选**：这是目前短线游资最推崇的“爆量战法”量化版本。
    3.  **盘中确认**：由于使用 `OPEN` 和 `HIGH`，建议在 9:25 集合竞价结束时运行选股。

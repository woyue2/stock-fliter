# 📈 主力强度 A*B*C 量化选股器

> 本工具专注于通过分析同花顺盘后**板块资金流向**，利用大单中单数据反推散户情绪，捕捉【真洗盘】与【真抢筹】的机会，规避诱多陷阱。

## 🚀 极简使用指南 (每日收盘后)

### 1️⃣ 准备数据 (导出同花顺)
每天中午或下午收盘后，打开手机版/PC版同花顺，进入相关板块资金页面，**导出两份表格**：
1. **热点/指数数据表** (需包含: `总金额`、`主力金额`、`涨幅` 等基本面指标)
2. **资金明细数据表** (需包含: `大单净流入`、`中单净流入` 等资金流指标)

导出的 Excel/xls 表格无需修改格式或改名。

### 2️⃣ 放入文件夹
将下载好的这**两份表格**，强行扔进本项目的 `input/` 文件夹内：
```text
check-zhulistrength/
 └─ input/  <-- 放在这里面 (原有的旧数据如果不想覆盖，可以不用管它，程序会自动匹配带 money 和 redian 的文件)
```
*(注意：请确保文件名中分别带有 `money` (对应资金流) 和 `redian` 或 `index` (对应热点总览) 关键字，程序靠此识别表身份)*

### 3️⃣ 一键执行
在终端中进入该目录，运行分析主程序：

```bash
cd /mnt/f/QIANQIAN/stock-fliter/check-zhulistrength/
python run_daily_scan.py
```

### 4️⃣ 查看战报
执行完毕后，分析结果将自动保存在 `output/` 文件夹内。你可以直接在编辑器中打开 `Analyzed_THS_xxxx.csv` 查看各板块的研判结果：
*   **找机会**：筛选【主力行为】为 `真抢筹` 或 `真洗盘` 且预期为 `上涨` 的板块。
*   **避风险**：远离被判定为 `阴跌`、`假抢筹`、或标注了 `(中单跟风过重)` 的板块。

## 🧠 核心判定逻辑备忘录

本策略引擎基于“零和博弈”定律运作：

*   **A (主力强度)** = `(主力总买入 / 总成交额) * 100`。此公式不受股票数量影响，直观反映大资金做多意愿。
*   **B (散户反指)** = `-(大单净额 + 中单净额)`。根据能量守恒，大单和中单在买，必然是小单（散户）在卖，由此精准抓取散户因恐慌交出筹码的绝佳买点。
*   **真假定理**：当 A 与 B 同向（即大单买，小单也买），则判定为**假动作 (诱多跟风)**。当且仅当 A 与 B 背离（大单吃货，纯散户割肉），方为**真实意图 (真洗/真买)**。

## 市场情绪
哥，在这套量化终端里，“市场情绪”百分比不是拍脑袋定的，它是一个**“盘面执行力”的宽度指标**。

根据 `gen_radial_report.py` 里的算法逻辑，它代表的意思是：
在当前页面这一组板块中，有多少比例的板块“动作是扎实的”？

具体到三个页面：

**策略狙击（恐慌错杀）**：
*   **指标意义**：代表**“反弹动能”**。
*   52.4% 意味着：在所有被识别为“错杀”的板块里，有 52.4% 的板块已经观察到主力强度翻正（主力开始干活了）。比例越高，说明错杀后的底部支撑越强。

**核心持仓（主力洗盘）**：
*   **指标意义**：代表**“洗盘成色”**。
*   意义：洗盘时，如果这个值很高，说明大部分处于洗盘阶段的板块，其主力强度依然维持在正数。这叫“洗盘不破位”，说明主力只是在赶人，没打算真撤。

**避险雷达（诱多陷阱）**：
*   **指标意义**：代表**“风险实锤度”**。
*   特别注意：这里的计算逻辑是反的。它代表有百分之多少的“疑似陷阱”板块，其强度已经跌破 0（实锤是陷阱了）。如果这个值达到 80%-90%，说明你看到的涨全是假的，风险已经全面扩散。

**简单一句话总结**：
这个数字越高，说明该页面的结论“可靠性”越强。
*   狙击页数值高 → 该买了；
*   洗盘页数值高 → 该拿住；
*   避险页数值高 → 快跑，全是坑。

## 强度的奥秘：板块下面的数字代表什么？

哥，板块下面那个带正负号的数字（比如 +0.99）是 **主力强度（Main Force Intensity）**。
在不同的页面，这个数字的“性格”是不一样的，你可以这么读：

### 1. 策略狙击（恐慌错杀）：代表“背离度”
这些板块通常股价在跌。
*   如果数字是 **正数（+）**：说明主力在**“捡钱包”**。股价越往下载，数字正值越大，说明主力“错杀”抄底的动作越狠。
*   如果数字是 **负数（-）**：说明还没跌透，主力也在砍仓参与踩踏，千万别急着接飞刀。

### 2. 核心持仓（主力洗盘）：代表“定力值”
*   如果数字是 **正数（+）**：说明主力在**“锁仓洗盘”**。外面散户在割肉跑路，但主力在里面稳如泰山，甚至还顺手接一点。数字越大，说明主力筹码拿得越死，洗完之后拉升的概率极高。
*   如果数字是 **负数（-）**：说明主力也在摇晃或减仓，洗盘可能演变成真的下跌。

### 3. 避险雷达（诱多陷阱）：代表“撤退速度”
这些板块表面上可能涨得挺好。
*   如果数字是 **负数（-）**：这是最危险的，说明主力在**“拉高出货”**。这就是诱多陷阱的证据：股价在往上拉，但主力强度在猛降，说明大资金正在借着涨势悄悄离场。数字负值越深，代表主力撤得越急，陷阱越深。

**💡 核心口诀**：
*   狙击页看“大正数”：主力在人弃我取。
*   洗盘页看“稳正数”：主力在震荡赶人。
*   避险页看“负数”：主力在忽悠散户，这是真的陷阱。

## 数值大小的意义：相对 VS 绝对

这个数字是 **绝对数值（强度分值）**，你可以把它理解为主力的“投入百分比”。它代表的不是排行，而是真金白银的参与烈度。数字的大小直接决定了结论的可靠程度：

**📈 1、2、3... 这些数字意味着什么？**

| 数值（绝对值） | 强度等级 | 盘面解释 |
| :--- | :--- | :--- |
| `0.0 ~ 0.5` | 微扰动 | 主力在打太极，动作不明确，多看少动。 |
| `0.5 ~ 1.5` | 标准波段 | 标准的洗盘或吸筹动作。这类板块是盘中的中坚力量，走势最稳。 |
| `1.5 ~ 3.0` | 高强度 | 主力已经急眼了！要么在暴力扫货（狙击页），要么在断崖式出逃（避险页）。 |
| `3.0 以上` | 极端异动 | 这种数字代表极致的恐慌或极致的疯狂。 |

**🔍 相对 VS 绝对：**
这个数字是“绝对分值”，但你在使用时应该**“看相对，定绝对”**：

*   **看相对（横向比）**：在同一张图里，圆圈最外层的、弧线最粗的（也就是数值绝对值最大的），是主力首选打击目标。比如同样是洗盘，电力 (+0.85) 就比 中药 (+0.26) 的洗盘成色足得多。
*   **定绝对（纵向看）**：通常 **1.0** 是个分水岭。
    *   `> 1.0`：代表主力有大动静，是绝对的信号。
    *   `< 1.0`：代表主力只是在跟随市场节奏，尚未爆发。

**总结：数字越大，代表主力的确定性越高。**
`+0.5` 的洗盘可能洗一半就跑了，但 `+2.0` 的洗盘说明主力已经把筹码吃进骨子里了。一眼望去，雷达图上最粗的那根线就是主力最核心的战场！

## 🚀 极简日常工作流
> 所有的混乱已被打包，你只需要按着这三步走。

### Step 1: 准备弹药 (放入数据)
每天盘后收盘，从同花顺导出最新的 **热点表 (`*redian*`)** 和 **资金表 (`*money*`)**，直接扔到 `input/` 目录里。（格式可以是 `.xls` 或者 `.csv`，系统全自动兼容解析）。

### Step 2: 启动量化雷达核心引擎 (计算)
不管你要出什么报告，先让系统脑子算一圈数据：
```bash
python run_daily_scan.py
```
*这句命令跑完后，所有的解析、修正和判定都会完成，并在 `output/` 目录下生成类似 `Analyzed_THS_0306.csv` 这样的终极母表数据。*

### Step 3: 提取雷达报告 (渲染)
核心数据算好后，你想要什么画风的报告，就跑下面对应的渲染脚本，它们都在 `reporters/` 里面躺好了，结果也会一律输出到 `output/` 目录中。

*   **【极简看盘 Pro版】**：买点、卖点、洗盘点最清晰，像手机 App 的卡片滑动。
    ```bash
    python reporters/gen_pro_report.py
    ```
*   **【V5 黑金大局观版】**：就是带圆圈刻度的，一眼看出全天主力在集火哪里，在抛弃哪里。
    ```bash
    python reporters/gen_radial_report.py
    ```
*   **【自媒体爆款文案】**：直接拿去发朋友圈、小红书、公众号的 Markdown 纯文案。
    ```bash
    python reporters/gen_media_report.py
    ```

**这就是它的核心：输入在左，产出在右，引擎在中间算，渲染器各司其职。**

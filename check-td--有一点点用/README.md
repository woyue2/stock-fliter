# TD分析分析系统

基于 TD分析 指标的多周期共振选股系统。

## 功能

- **日线九底**: 日K线 TD 序列 ≥ 9
- **周线九底**: 周K线 TD 序列 ≥ 9
- **月线九底**: 月K线 TD 序列 ≥ 9
- **多周期共振**: 支持 7底/8底/9底 的单周期、双周期、三周期组合分析

## 底部信号组合

系统支持完整的底部信号组合，按优先级降序排列：

### 单周期组合
| 周期 | 9底 | 8底 | 7底 |
|-----|-----|-----|-----|
| 日线 | 日9底 | 日8底 | 日7底 |
| 周线 | 周9底 | 周8底 | 周7底 |
| 月线 | 月9底 | 月8底 | 月7底 |

### 双周期组合
| 组合 | 9底 | 8底 | 7底 |
|-----|-----|-----|-----|
| 日周 | 日周9底 | 日周8底 | 日周7底 |
| 日月 | 日月9底 | 日月8底 | 日月7底 |
| 周月 | 周月9底 | 周月8底 | 周月7底 |

### 三周期组合
| 组合 | 9底 | 8底 | 7底 |
|-----|-----|-----|-----|
| 日周月 | 日周月9底 | 日周月8底 | 日周月7底 |

### 排序规则
按**周期数降序** → 同周期时按**阈值降序**排列：
```
日周月9 > 日周月8 > 日周月7 > 日周9 > 日月9 > 周月9 > 日周8 > 日月8 > 周月8 > ... > 单周期9 > 单周期8 > 单周期7
```

### 底部详情示例
- 全部9底: `日周月9+日周月8+日周月7+日周9+日月9+周月9+日周8+日月8+周月8+日周7+日月7+周月7+日9+周9+月9+日8+周8+月8+日7+周7+月7`
- 日周双周期8底: `日周8+日周7+日8+周8+日7+周7`
- 三周期7底: `日周月7+日周7+日月7+周月7+日7+周7+月7`

## 快速开始

### 环境准备

1. 确保已安装 Python 3.8+
2. 安装依赖包：
```bash
pip install pandas tqdm baostock
```

### 运行分析

```bash

# 或直接运行 Python
python main.py
```

## TD分析 算法

TD 序列通过比较当前收盘价与 4 周期前的收盘价来计算：

```
如果 close[i] < close[i-4]:
    TD计数 += 1 (最大为 9，超过则重新从 1 计数)
否则:
    TD计数 = 0
```

当 TD 计数达到 9 时，表示可能的底部信号（九底）。

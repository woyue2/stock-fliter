## 🎯 三种使用模式

### 模式1：全市场扫描（找出所有三周期共振股票）

```bash
python jiudi_scanner.py
```

**特点**：
- ✅ 扫描全部5300+只A股
- ⏱️ 耗时：15-25分钟
- 🎯 最全面，最可能找到三周期共振股票

### 模式2：快速测试（扫描50只股票）

```bash
python test_50.py
```

**特点**：
- ✅ 快速验证系统功能
- ⏱️ 耗时：30秒-1分钟
- 🎯 适合日常快速查看

### 模式3：自定义扫描

修改 `jiudi_scanner.py`：

```python
# 扫描沪深300（约300只）
scanner.scan_market(max_workers=20, limit=300)

# 扫描中证500（约500只）
scanner.scan_market(max_workers=20, limit=500)
```

## 📊 输出文件说明

扫描完成后，在 `output/` 目录会生成：

### 1. 三周期九底共振_YYYYMMDD_HHMMSS.csv
**最重要！** 包含同时达到日K、周K、月K九底的股票

**字段说明**：
```
code        - 股票代码
name        - 股票名称
latest_price - 最新收盘价
daily_count - 日K九底序列值（≥9为九底）
weekly_count - 周K九底序列值（≥9为九底）
monthly_count - 月K九底序列值（≥9为九底）
is_resonance - 是否三周期共振
```

### 2. 双周期共振_YYYYMMDD_HHMMSS.csv
包含两个周期达到九底的股票

### 3. 全部分析结果_YYYYMMDD_HHMMSS.csv
包含所有被分析股票的TD序列数据

## ⚠️ 注意事项

### 1. 三周期共振极其罕见
- 可能全市场只有0-5只
- 需要耐心等待
- 一旦出现要重点关注

### 2. 九底≠必涨
- 技术指标仅供参考
- 需结合基本面分析
- 严格止损很重要

### 3. 系统运行时间
- 全市场扫描：15-25分钟
- 取决于网络速度和CPU性能
- 建议在网络良好时运行

## 🔧 常见问题

### Q1: 扫描速度慢？
**A**: 调整线程数
```python
# 在 jiudi_scanner.py 中修改
scanner.scan_market(max_workers=30)  # 增加到30线程
```

### Q2: 没有找到三周期共振？
**A**: 正常！三周期共振非常罕见，可以关注：
- 双周期共振股票
- 单周期九底股票
- 接近九底（序列≥7）的股票

### Q3: 如何判断股票价值？
**A**: 结合多个指标：
- 九底形态（技术面）
- PE/PB估值（估值面）
- PEG指标（成长性）
- 成交量（资金面）

# 股票行业信息更新工具

## 功能说明

使用 akshare 模块获取股票行业信息，并更新到 `data/selected_stocks_all.csv` 文件中。

## 使用方法

### 方法1：使用批处理文件（推荐）

双击运行 `update_industry.bat`

### 方法2：使用命令行

```bash
cd get-data
python fetch_industry_akshare.py
```

## 工作流程

1. 读取 `data/selected_stocks_all.csv` 文件
2. 使用 akshare 获取所有A股的行业信息
3. 匹配股票代码，更新行业列
4. 保存回原文件

## 数据来源

- **主要方法**: `ak.stock_info_a_code_name()` - 获取A股基本信息
- **备用方法**: `ak.stock_zh_a_spot_em()` - 获取沪深京A股实时行情（包含行业）

## 注意事项

1. 需要安装 akshare 模块：`pip install akshare`
2. 需要网络连接以获取最新数据
3. 首次运行可能需要较长时间
4. 更新后的文件会覆盖原文件，建议先备份

## 文件说明

- `fetch_industry_akshare.py` - 主程序脚本
- `update_industry.bat` - Windows批处理启动文件
- `data/selected_stocks_all.csv` - 股票列表文件（包含行业信息）

## 与 HTML 报告的集成

更新行业信息后，运行 `check-steady-uptrend` 模块生成的 HTML 报告将自动显示：

1. **股票列表中的行业**: 在股票名称后以括号形式显示，如 "浦发银行 (银行)"
2. **行业统计**: 在侧边栏显示行业分布统计
3. **已勾选股票**: 在总览页面的已勾选股票中也会显示行业标签

## 故障排除

### 问题：无法获取行业信息

**解决方案**:
- 检查网络连接
- 确认 akshare 已正确安装：`pip install --upgrade akshare`
- 查看错误信息，可能是 API 变更

### 问题：部分股票没有行业信息

**原因**: 
- 新上市股票可能暂未分类
- 退市或停牌股票可能无数据

**处理**: 这些股票的行业字段会保持为空，不影响其他功能

## 更新频率建议

- **日常使用**: 每月更新一次即可
- **新股上市**: 有新股关注时更新
- **行业调整**: 证监会调整行业分类后更新

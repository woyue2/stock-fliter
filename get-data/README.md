# get-data

这是一个独立的数据获取模块，负责从网络获取股票数据并统一存储。

## 目录结构

- `main.py`: 主程序，支持增量更新、随机采样、全市场扫描。
- `data/raw/`: 存放每只股票的 CSV 文件 (例如 `000001.csv`)。
- `data/selected_stocks.csv`: 存放最近一次筛选/获取的股票列表。
- `output/`: 存放每次运行的摘要日志。

## 使用方法

### 1. 更新默认股票池 (随机10只)
```bash
python main.py
```

### 2. 更新指定数量的随机股票
```bash
python main.py --sample-size 50 --resample
```

### 3. 全市场扫描 (获取所有A股数据)
```bash
python main.py --all
```

### 功能特性
- **断点续传**: 程序会自动检测本地文件日期，若已是最新数据（今日）则自动跳过，支持中断后快速恢复。
- **增量更新**: 仅获取本地缺失的日期范围，减少网络请求。
- **最新日期显示**: 运行结束时会显示获取到的数据中的最新日期。

# 连板天梯深度分析技能

此技能已全面升级自动化流程：它会自动从 `raw/` 目录中抓取最新的未经整理的文本（或制表符分隔的内容），清洗格式后永久归档到 `archieve/` 中，随后立刻为您生成极具实战意义的复盘研判。

## 目录结构说明

- `raw/`: 存放您每日从软件中复制出来的最原始数据（如 `0311连板天梯.csv`）。**运行脚本后，这里的文件会被自动格式化并移走。**
- `archieve/`: 存放已经清洗过的、随时可以直接用 Excel 打开的历史标准 CSV 数据。
- `scripts/`: 存放强大的 `analyze.py` 核心自动化分析脚本。

## 运行方式

在项目目录下运行：

```bash
python3 /mnt/f/QIANQIAN/stock-fliter/连板天梯/scripts/analyze.py
```

## 自动化深度研判 (自动输出)

脚本已经内置并自动化解答了以下核心深度复盘问题：

1. **💡 潜在主线逻辑预测 (未来 2-3 天)** 
   - 脚本通过分析跨梯队的高频关键词群，结合虹吸效应算法，直接告诉您哪个题材正在接管整个市场的情绪，值得重仓死磕。
2. **🚀 补涨逻辑扩散研判 (高低切)**
   - 脚本会锁定那些“同时在二板及以上打出高度，并且在首板大面积爆发”的题材。一旦这些数据共振，说明大资金正在底层开启低位补涨挖掘模式，给您提供埋伏首板的安全方向。
3. **📊 题材情绪强度对比 (与昨日对比)** 
   - 只要 `archieve/` 里有前几日的数据，脚本会自动抽调昨日的涨停数与核心题材库，一一对比今日的留存情况。直接揭示龙头板块是在“爆发发酵”还是“濒临淘汰”。
4. **🪜 完整梯队结构探测 (主线确认)**
   - 脚本会通过扫描发现那些在“首板、二板、三板、四板及以上”各级高度均有股票身位的题材。
   - 这种“排队式”分布是确立主线题材的核心标准。脚本会识别并高亮显示这些具有“完整天梯感”的超级主线。
5. **📍 区域热力分布 (省份垂直统计)**
   - 脚本会自动识别每只涨停股所在的省份/直辖市（通过名称前缀、涨停原因中的国资背景、及内置的万得口径手动映射表）。
   - 它可以帮您捕捉到隐蔽的“地域概念炒作”，例如某地国资委的集体整合预期，并在生成的 CSV 表格中，直接在股票名字后显示 **(地区)**，例如 `中南文化(江苏)`。

您不再需要手动提问这五条 Prompt，脚本的输出直接给出上述维度的统计与 **AI 解盘结论**！如果想针对特定版块或个股名称进行深入提问，您可以将脚本生成的报告全文发给 AI 助手，让其结合当前政策面做更宏观的预测。

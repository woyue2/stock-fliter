# 资金雷达每日运行工作流 (stock_daily_run)

这个工作流封装了「主力资金雷达」的完整每日发布流程，从数据放入到 HTML 报告生成，一共三步。

**前置条件**：
1. 每日盘后，从同花顺导出最新的 **热点表（`*redian*`）** 和 **资金表（`*money*`）**，扔进以下目录：
   ```
   /mnt/f/QIANQIAN/stock-fliter/资金出入(自媒体)/input/
   ```
2. 格式支持 `.xls` 或 `.csv`，系统全自动兼容解析。

---

// turbo
1. **Step 1：启动量化雷达核心引擎（数据计算）**

   执行核心扫描脚本，完成所有板块的主力强度解析、信号判定，并在 `output/` 目录生成终极母表（如 `Analyzed_THS_MMDD.csv`）：
   ```bash
   cd /mnt/f/QIANQIAN/stock-fliter/资金出入(自媒体) && python run_daily_scan.py
   ```
   执行完毕后，告知用户 `output/` 目录下生成了哪些文件——尤其是 `Analyzed_THS_*.csv` 的文件名和时间。

// turbo
2. **Step 2：渲染 V5 黑金大局观雷达报告（可视化）**

   核心数据就绪后，运行雷达渲染器，生成带圆圈刻度的辐射状 HTML 报告，一眼看清全天主力在集火哪里、在抛弃哪里：
   ```bash
   cd /mnt/f/QIANQIAN/stock-fliter/资金出入(自媒体) && python reporters/gen_radial_report.py
   ```
   执行完毕后，列出 `output/` 目录下新生成的 HTML 文件名，并提醒用户：**用 Chrome（bca 账户）打开对应 HTML 文件进行手动截图**。

3. **Step 3：发布提示（截图 → 发布）**

   提醒用户以下发布流程：
   - 📸 **截图**：用 Chrome 浏览器（bca 账户）打开 HTML，截取完整报告画面。
   - 🎵 **抖音**：发布截图，文案**简短为主**（10字以内标题，突出今日最强/最危信号板块）。
   - 📕 **小红书 & 快手**：同步发布截图，文案可略长，附上板块信号解读。

   同时，AI 根据 `output/Analyzed_THS_*.csv` 中的数据，自动生成一段**简短社媒文案参考**，格式如下：
   ```
   【今日主力雷达 MM月DD日】
   🔥 扫货最猛：[板块名] (+X.XX 强度)
   ✅ 蓄势待发：[板块名] 洗盘中（+X.XX 定力值）
   ⚠️ 警报拉响：[板块名] 疑似出货（-X.XX）
   #主力资金 #板块轮动 #A股
   ```

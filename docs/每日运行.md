# 🚀 每日运行指南 (2026版)

## 0. 统一调度脚本 (推荐)
一键全流程运行（数据获取 + 所有分析模块 + 索引生成）：
```bash
python run_all_strategies.py
```

---

## 🛠️ 分步运行手动流程

### 第一步：数据获取 (get-data)
**推荐方案（极速快照，约 20 秒）：**
```bash
cd get-data && python services/fetch_daily_snap.py
```

**补数据方案（慢速同步，用于缺失多天数据）：**
```bash
cd get-data && python services/fetch_daily_history.py --all
```

**同步行业信息 (BaoStock 版)：**
```bash
cd get-data && python fetchers/fetch_industry_baostock.py
```

---

### 第二步：分析模块 (check-*)
按需运行各个分析模块：
```bash
cd check-td && python main.py
cd check-maxrsix6u1d && python main.py
cd check-tdxmacdxvolume && python main.py
cd check-volupxyangxshipan && python main.py  # 量价确认 / 实盘逻辑
cd check-zhulistrength && python main.py      # A*B*C 主力强度分析
```

---

### 第三步：生成汇总报告索引
```bash
cd scripts && python build_reports_index.py
```

---

### 🕒 可选：分钟数据 (分时分析)
```bash
cd get-data && python fetchers/fetch_minute_akshare.py --all --realtime
```

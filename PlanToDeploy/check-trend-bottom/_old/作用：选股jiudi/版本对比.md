# 版本功能对比

## v1.0 vs v1.1

### 主要区别

| 功能 | v1.0（旧版） | v1.1（新版）✨ |
|-----|-------------|---------------|
| **关注范围** | 只看序列≥9 | 也关注序列7-8 ✅ |
| **分类数量** | 3类 | 5类 ✅ |
| **输出文件** | 3个 | 6个 ✅ |
| **候选股票** | 极少 | 更多机会 ✅ |

```
output/
├── 三周期九底共振_*.csv
├── 双周期共振_*.csv
└── 全部分析结果_*.csv
```

### v1.1 输出（6个文件）
```
output/
├── 三周期九底共振_*.csv        （≥9）

├── 接近九底_*.csv              （7-8）✨新增
└── 全部分析结果_*.csv
```

## 新增的分类逻辑

### v1.0 分类（3类）
```
1. 三周期共振（三个周期≥9）
2. 双周期共振（两个周期≥9）
3. 单周期九底（一个周期≥9）
```

### v1.1 分类（5类）
```
1. 三周期共振（三个周期≥9）
2. 接近三周期共振（三个周期≥7）✨新增
3. 双周期共振（两个周期≥9）
4. 单周期九底（一个周期≥9）✨新增
5. 接近九底（至少一个周期7-8）✨新增
```

## 使用建议对比

### v1.0 策略
```
只等待序列9确认：
✅ 优点：信号明确，成功率相对较高
❌ 缺点：可能错过最佳买点，候选股票极少
```

### v1.1 策略
```
提前关注序列7-8：
✅ 优点：提前布局，更多机会
✅ 结合其他指标判断（PE/PB/成交量）
❌ 缺点：需要更严格的风控
```

## 推荐操作流程

### v1.0（旧版）
```
1. 运行扫描
2. 找到三周期共振股票
3. 分析基本面
4. 买入
```

### v1.1（新版）✨推荐
```
1. 运行扫描
2. 查看"接近九底"文件（序列7-8）
3. 筛选PE/PB合理的股票
4. 观察成交量变化
5. 分批建仓：
   - 序列7-8：小仓位试探
   - 序列9：确认后加仓
   - 突破九底最高点：继续加仓
```

**v1.1 的改进让您能够：**

## ✨ 新增功能

### 1. 新增分类类别

#### 完美形态
- **三周期共振（≥9）**：日K、周K、月K都达到九底
- **接近三周期共振（≥7）**：三个周期都达到序列7以上

#### 常见形态
- **双周期共振（≥9）**：两个周期达到九底
- **单周期九底（≥9）**：一个周期达到九底

#### 值得关注（新增）
- **接近九底（序列7-8）**：至少一个周期在7-8之间

## 🔍 分类逻辑详解

### 优先级排序（从高到低）

```python
# 1. 三周期共振
if 日K ≥ 9 and 周K ≥ 9 and 月K ≥ 9:
    分类 = "三周期共振"

# 2. 接近三周期共振
elif 日K ≥ 7 and 周K ≥ 7 and 月K ≥ 7:
    分类 = "接近三周期共振"

# 3. 双周期共振
elif 两个周期 ≥ 9:
    分类 = "双周期共振"

# 4. 单周期九底
elif 一个周期 ≥ 9:
    分类 = "单周期九底"

# 5. 接近九底（新增）
elif 至少一个周期在 7-8 之间:
    分类 = "接近九底"

# 6. 其他
else:
    分类 = "无共振"
```

### 示例

| 日K | 周K | 月K | 分类 |
|-----|-----|-----|------|
| 11 | 10 | 9 | 三周期共振 |
| 8 | 8 | 7 | 接近三周期共振 |
| 9 | 10 | 3 | 双周期共振 |
| 9 | 2 | 1 | 单周期九底 |
| 8 | 3 | 2 | 接近九底 ⭐ |
| 7 | 0 | 0 | 接近九底 ⭐ |
| 4 | 2 | 1 | 无共振 |

## 💡 使用建议

### 为什么关注序列7-8？

1. **提前布局**
   - 序列9确认时可能已经反弹
   - 序列7-8可以提前建仓

2. **提高成功率**
   - 等到序列9可能错过最佳买点
   - 序列7-8结合其他指标判断更准确

3. **增加候选股票**
   - 序列9极其罕见
   - 序列7-8相对常见，提供更多机会

### 操作策略

#### 序列7-8（接近九底）
```
✅ 建议操作：
- 观察为主，小仓位试探
- 设置止损（九底最低价）
- 等待确认信号（放量上涨）
- 结合PE/PB估值判断

⚠️ 风险提示：
- 可能失败，继续下跌
- 需要严格止损
- 不要重仓
```

#### 序列9（确认九底）
```
✅ 建议操作：
- 可以适当加仓
- 确认反弹信号后买入
- 设置止盈止损

⚠️ 仍需注意：
- 九底不保证上涨
- 结合市场环境
- 控制仓位
```

## ⚠️ 重要提示

### 序列7-8 ≠ 序列9
- 序列7-8：接近九底，**可能**形成九底
- 序列9：确认九底，但**不保证**上涨
- 都需要结合其他指标判断

### 操作纪律
1. **严格止损**：跌破关键位置立即止损
2. **控制仓位**：不要满仓单一股票
3. **分散投资**：选择多只候选股票
4. **持续观察**：九底后需要确认信号

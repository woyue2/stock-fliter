## 用途

每个交易日开盘前（建议 09:00-09:20 之间）运行此流程，完成数据同步、信号扫描与知识输入，确保当日有数据可分析、有信号可决策。

---

## 步骤

### Step 1：拉取当日日线行情

// turbo
1. 运行日线快照拉取脚本（增量更新当日行情到 stocks.db）
   CommandLine: python3 /mnt/f/QIANQIAN/stock-fliter/get-data/services/fetch_daily_snap.py

> ✅ 完成后检查输出，确认更新了多少只股票。若报错，检查网络或 baostock 登录状态。

---

### Step 2：运行 TD 底部信号扫描

// turbo
2. 运行 TD Sequential 策略扫描（使用本地已有数据）
   CommandLine: python3 /mnt/f/QIANQIAN/stock-fliter/check-td--有一点点用/main.py --skip-fetch

> ✅ 扫描结果输出到 `check-td--有一点点用/output/` 下的最新目录，关注 TD9/TD13 信号标的。

---

### Step 3：归档连板天梯数据（人工操作）

3. **从同花顺软件复制当日连板天梯数据**，粘贴为文本文件，命名格式：`MMDD.csv` 或 `MMDD连板天梯.csv`，放入：

   ```
   /mnt/f/QIANQIAN/stock-fliter/连板天梯/raw/
   ```

4. 运行连板天梯分析脚本，自动清洗归档并生成今日研判报告：

   ```bash
   python3 /mnt/f/QIANQIAN/stock-fliter/连板天梯/scripts/analyze.py
   ```

   > ✅ 脚本会自动将 `raw/` 下的文件清洗后移至 `archieve/`，并生成 `report/MMDD_report.md`。
   > 报告涵盖：情绪评级、主线梯队、高低切信号、区域热力。

---

### Step 4：获取同花顺资金流动数据（人工操作）

5. 在同花顺软件中，分别导出**当日资金流动**数据：
   - **行业资金流向**（按一级行业排列）
   - **概念资金流向**（按热门概念排列）

6. 将导出文件保存到：

   ```
   /mnt/f/QIANQIAN/stock-fliter/所有板块/
   ```

   并在对话中发给 AI，触发 `/板块推演` 或 `/低位埋伏` 指令进行深度分析。

> 💡 资金流向是判断当日主线和题材扩散方向的最直接信号，与连板天梯互相印证。

---

### Step 5：看机构底牌（情报收集，只看不买）

7. 打开东方财富/同花顺，浏览以下内容形成今日市场感知：

   | 信息源 | 关注点 |
   |--------|--------|
   | 龙虎榜净买入 Top10 | 大资金今日布局在哪 |
   | 机构调研最新公告 | 哪些股被机构盯上 |
   | 涨停板复盘 | 首板/二板题材逻辑是否清晰 |
   | 主力持仓变动 | 近期有没有悄悄建仓的迹象 |

   > ⚠️ **只看不买**：情报收集阶段，只是建立候选名单和感知市场情绪，不做任何实际交易决策。

---

### Step 6：今日学习（知识积累）

8. 完成至少一项知识输入，选择以下之一：

   - 📺 下载或观看一节公开课（推荐：缠论 / 龙头战法 / 资金博弈相关）
   - 📚 阅读一篇行业研报（对照当日涨停题材，理解底层逻辑）
   - 🗒️ 写一条今日复盘笔记到 `交易日记` 文件中

   > 💡 市场每天都在考你，学习是唯一能让你"比市场慢一步"变成"比市场快一步"的方式。

---

## 完成标志

运行结束后，在对话中对 AI 说以下任一指令，进入正式分析阶段：

```
/复盘 MMDD           ← 读取今日梯队报告做全局复盘
/低位埋伏 [热点题材]  ← 以今日高标为锚，挖低位分支
/单股诊断 [股票名]   ← 诊断某只你关注的标的
```

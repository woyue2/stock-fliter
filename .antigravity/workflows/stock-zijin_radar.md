# 资金出入雷达自媒体工作流 (zijin_radar)

这个工作流封装了「主力资金雷达」的完整每日发布流程，从同花顺数据计算到 V5 黑金雷达图生成，以及最后的自媒体平台发布建议。

**前置条件**：
1. 每天盘后收盘，从同花顺导出最新的 **热点表（需包含 `redian` 关键字）** 和 **资金表（需包含 `money` 关键字）**。
2. 将文件放入以下目录（支持 `.xls` 或 `.csv`，系统全自动兼容解析）：
   ```
   /mnt/f/QIANQIAN/stock-fliter/资金出入(自媒体)/input/
   ```

// turbo-all

### 1. 启动量化雷达核心引擎 (数据扫描与计算)
不管要出什么风格的报告，首先让系统引擎计算数据，生成最新判定：
```bash
cd "/mnt/f/QIANQIAN/stock-fliter/资金出入(自媒体)" && python3 run_daily_scan.py
```
> **说明**：这句命令跑完后，所有的解析、修正和判定都会完成，并在 `output/` 目录下生成类似 `Analyzed_THS_MMDD.csv` 这样的终极母表数据。AI 会读取并确认文件生成成功。

### 2. 提取雷达报告 (V5 黑金大局观版渲染)
生成一目了然的主力集火/抛弃雷达图页面：
```bash
cd "/mnt/f/QIANQIAN/stock-fliter/资金出入(自媒体)" && python3 reporters/gen_radial_report.py
```
> **说明**：执行后会在 `output/` 目录下生成 HTML 文件。这个带圆圈刻度的报告能一眼看出全天真正的主力发力点。

### 3. 生成自媒体快捷文案 & 发布提醒 (AI 动作)
渲染完成后，根据以下流程操作：
- **AI 动作**：读取 `output/` 目录中最新生成的 `Analyzed_THS_XX.csv` 文件，自动挑选出 **狙击页最高强度**、**洗盘页最高定力值**、**避险页最深陷阱** 的 1-3 个代表性板块，生成一段极简的自媒体标题/文案供你直接复制粘贴。
  格式参考：
  ```text
  【今日主力雷达 MM月DD日】
  🔥 扫货最猛：[板块名] (+X.XX)
  ✅ 洗盘震仓：[板块名] (+X.XX)
  ⚠️ 诱多陷阱：[板块名] (-X.XX)
  ```
- **用户手动操作**：
  1. 打开 Chrome 浏览器（使用 bca 账户），预览刚刚生成的 HTML 报告并手动截图。
  2. 首发 **抖音**（文案简短，只放核心亮点）。
  3. 同步分发 **小红书** 和 **快手**。

# 报告索引 HTML 方案

## 可行性结论

**可行。** 两个模块的输出结构一致，且入口均为 `summary_*.html`，便于统一扫描与「按日期 + 同日期取最新时间戳」规则生成索引。

---

## 现有输出结构（不变）

| 模块 | 输出根目录 | 目录结构 | 入口 HTML |

|------|------------|----------|-----------|

| 稳步上升 | [check-steady-uptrend/output](check-steady-uptrend/output) | `YYYY-MM-DD` / `HH-MM-SS` / | `summary_{YYYYMMDD}_{HHMMSS}.html` |

| TD九底 | [check-trend-bottom/output](check-trend-bottom/output) | `YYYY-MM-DD` / `HH-MM-SS` / | `summary_{YYYYMMDD}_{HHMMSS}.html` |

同一日期下可能有多条 `HH-MM-SS`（多次运行）；索引规则：**每个日期只保留该日最新的一条时间戳**，链接到该时间戳目录下的 summary 页。

---

## 实现思路

1. **扫描**：对每个模块的 `output` 做一次遍历，收集所有 `YYYY-MM-DD`，再在每个日期下找**最新**的 `HH-MM-SS` 目录，并在该目录下取 `summary_*.html`（通常只有一个）。
2. **聚合**：按日期汇总，得到「日期 → 模块名 → 报告相对路径」。
3. **生成索引页**：写一个静态 HTML（如 `reports_index.html`），表格列为「日期 | 稳步上升 | TD九底」，单元格为指向对应 summary 的超链接（无报告则留空或「-」）。链接使用**相对路径**，保证本地双击打开 index 即可跳转。
4. **放置位置**：索引页放在**项目根目录**，链接形如 `check-steady-uptrend/output/2026-01-30/14-30-00/summary_xxx.html`，这样与当前各模块 output 路径一致，无需改动现有 pipeline。

---

## 建议目录与文件

- **脚本**：根目录下 `scripts/build_reports_index.py`（或 `build_reports_index.py`）。  
  - 输入：配置好的「模块显示名 → output 相对路径」列表（相对项目根）。  
  - 输出：在项目根生成 `reports_index.html`。
- **索引页**：`reports_index.html`（项目根），由脚本覆盖生成。

可选：在 `run.bat` 或各模块运行后不自动调用该脚本，仅在文档中说明「需要更新索引时执行 `python scripts/build_reports_index.py`」；若希望每次跑完自动更新索引，再在对应 pipeline 或 bat 末尾增加一次调用。

---

## 脚本核心逻辑（伪代码）

```text
CONFIG = [
    ("稳步上升", "check-steady-uptrend/output"),
    ("TD九底", "check-trend-bottom/output"),
]
# 1. 对每个 (name, output_root):
#    - 若 output_root 不存在则跳过
#    - 遍历 output_root 下子目录，匹配 YYYY-MM-DD
#    - 对每个日期目录，列出其下 HH-MM-SS 子目录，按名称排序取最新
#    - 在该最新时间戳目录下 glob summary_*.html，取第一个作为该日期该模块的报告路径
# 2. 汇总为: date -> { module_name -> relative_path }
# 3. 日期按降序排列（最新在前）
# 4. 用模板生成 HTML：表头「日期 | 稳步上升 | TD九底」，每行一个日期，单元格为 <a href="...">日期或「查看」</a>
```

相对路径均以**项目根**为基准，这样 `reports_index.html` 与各 output 的相对关系固定，本地打开即可用。

---

## 索引页展示形态（示例）

- 标题：选股报告索引（或你指定的标题）。
- 表格：列 = 日期、稳步上升、TD九底；行 = 每个出现过的日期（去重、降序）。
- 单元格：有报告则为「查看」或日期链接到对应 `summary_*.html`，无则为 `-`。
- 样式：简单内联或 `<style>`，便于本地打开即可用、无需服务器。

---

## 注意事项

1. **file:// 与相对路径**：索引页与链接都使用相对路径，在资源管理器中双击 `reports_index.html` 用浏览器打开时，链接可正常访问同一机器上的其它本地 HTML。
2. **仅读现有 output**：脚本只读各 `output` 目录并写 `reports_index.html`，不修改、不删除任何已有报告。
3. **同日期多时间戳**：严格按「同日期只取最新 `HH-MM-SS`」实现，与你的「同一日期以最新生成的时间戳为准」一致。
4. **扩展性**：若后续增加新模块（如 check-new-indicators），只需在 CONFIG 中增加一项 `(显示名, output 相对路径)` 并在表格中增加一列即可。

# 股票筛选系统 - 重构版

该系统用于A股市场的技术分析筛选，支持多种分析策略的组合使用。

## 快速开始

```bash
# 方式1：双击运行
run.bat

# 方式2：命令行运行
python main.py --skip-fetch    # 使用已有分析结果
python main.py                 # 完整分析流程
```

## 分析器说明

### 1. MAxRSIx6U1D分析 (代号: 1)

判断股票是否处于稳定上升趋势：
- 均线多头排列（MA5 > MA10 > MA20 > MA30 > MA60）
- 价格站在所有均线之上
- 60日最大回撤在可控范围内

### 2. 趋势分析 (代号: 3)

包含三种趋势规则：
- **趋势跟随**: MA20 > MA60，斜率为正，价格 > MA20
- **上升回撤**: 上升趋势中的回调，RSI在40-55区间
- **波动收缩突破**: 布林带收窄后突破，放量确认

### 3. 网格测试 (代号: 4)

对波动收缩突破参数进行网格搜索优化，找出最优参数组合。

### 4. 玄学指标 (代号: x)

**🆕 现在提供两套玄学指标供对比观察：**

#### 原版指标（严格版）
基于严格连续阳线模式：
- **6连阳+1阴**: 10天窗口内存在连续6天阳线后1天阴线
- **连续6阳**: 最近6天全部阳线（不允许任何阴线）

#### 容忍版指标（Tolerant）
允许小幅回调（跌幅 < 1.64%）：
- **6有效涨+1真跌**: 10天窗口内存在连续6天有效涨后1天真跌
- **连续6有效涨**: 最近6天全部有效涨（可包含小跌）

**详细说明请查看：[玄学指标说明.md](./玄学指标说明.md)**

## 玄学指标优先级

### 原版优先级
| 优先级 | 标记 | 条件 | 含义 |
|--------|------|------|------|
| 1 | [STAR]买入 | 6连阳后阴线 | 最佳买入机会，立即行动 |
| 2 | [STAR]等待 | 第6天阳线 | 等明天回调再买 |
| 3 | ◆连阳 | 最近6天连续阳线 | 连续上涨中 |
| 4 | ○模式 | 10天内有6连阳模式 | 符合模式 |

### 容忍版优先级
| 优先级 | 标记 | 条件 | 含义 |
|--------|------|------|------|
| 1 | [STAR]买入-小回调 | 6连涨后小跌 | 最佳买入机会，立即行动 |
| 2 | [STAR]等待-连涨中 | 第6天有效涨 | 等待回调 |
| 3 | ◆连涨中 | 最近6天有效连涨 | 稳健上涨中 |
| 4 | ○模式 | 10天内有6连涨模式 | 符合模式 |

## 组合策略

**🆕 现在提供 28 种组合**（原版14种 + 容忍版14种）

### 分析器组合

| 组合代号 | 说明 | 组合条件 |
|----------|------|----------|
| 134 | 最严格 | MAxRSIx6U1D + 趋势分析 + 网格测试 |
| 13 | 稳步+趋势 | MAxRSIx6U1D + 趋势分析 |
| 34 | 趋势+网格 | 趋势分析 + 网格测试 |
| 14 | 稳步+网格 | MAxRSIx6U1D + 网格测试 |
| 3 | 仅趋势 | 趋势分析 |
| 1 | 仅稳步 | MAxRSIx6U1D |
| 4 | 仅网格 | 网格测试 |

### 玄学条件

每种组合支持 4 种玄学条件：

| 后缀 | 说明 | 版本 |
|------|------|------|
| `_6` | 连续6天阳线 | 原版（严格） |
| `_61` | 近10天6涨1跌 | 原版（严格） |
| `_6t` | 连续6天有效涨（容忍小跌<1.64%） | 容忍版 |
| `_61t` | 近10天6有效涨1真跌（容忍小跌<1.64%） | 容忍版 |

### 示例

- `xuanxue_134_6`: 1+3+4组合 + 连续6天阳线（原版）
- `xuanxue_134_6t`: 1+3+4组合 + 连续6天有效涨（容忍版）
- `xuanxue_3_61`: 仅趋势分析 + 近10天6涨1跌（原版）
- `xuanxue_3_61t`: 仅趋势分析 + 近10天6有效涨1真跌（容忍版）

## 命令行参数

```bash
python main.py [选项]

选项:
  --skip-fetch          跳过数据获取，使用已有分析结果
  --only-report         仅生成报告（需要已有分析结果）
  --analyzers ANALYZERS 指定分析器: 1=MAxRSIx6U1D, 3=趋势, 4=网格, x=玄学
  --limit LIMIT         限制扫描股票数量
  --output-dir DIR      输出目录
  --grid-horizon N      网格测试收益周期（默认20天）
```

## 输出文件

每次运行会在 `output/YYYY-MM-DD/HH-MM-SS/` 目录下生成：

### CSV文件

**原版文件**：
- `xuanxue_XXX_N只_baseon_MMDDYYYY_YYYYMMDD_HHMMSS.csv`
- 包含所有符合条件的股票

**容忍版文件（仅显示新增）**：
- `xuanxue_XXX_N只_新增M只_总K只_baseon_MMDDYYYY_YYYYMMDD_HHMMSS.csv`
- **仅包含容忍版相比原版额外捕捉到的股票**
- N = 新增数量，K = 总数量（包含原版已有的）

> 💡 **重要**：容忍版文件只显示原版中没有的股票，避免重复，更直观！
> 详细说明请查看：[容忍版显示说明.md](./容忍版显示说明.md)

### MD报告
- `xuanxue_XXX_N只_baseon_MMDDYYYY_YYYYMMDD_HHMMSS.md`
- `summary_report_YYYYMMDD_HHMMSS.md`

### HTML报告
- `xuanxue_XXX_N只_YYYYMMDD_HHMMSS.html` - 可交互，点击股票直接打开东方财富页面
- `summary_YYYYMMDD_HHMMSS.html` - 总览页面

## 使用建议

### 如何选择版本？

**选择原版（严格版）如果你：**
- ✅ 偏好强势连续上涨的股票
- ✅ 希望减少假信号
- ✅ 愿意接受较少的候选股票
- ✅ 追求高质量而非高数量

**选择容忍版如果你：**
- ✅ 认为小幅震荡是正常的
- ✅ 希望获得更多候选股票
- ✅ 愿意接受一定的波动
- ✅ 追求更广的覆盖面

### 对比观察

建议同时运行两个版本，对比结果：
1. **原版 vs 容忍版**：哪个版本的命中率更高？
2. **不同组合**：134、13、3、34、14、1、4 哪个组合效果最好？
3. **不同玄学条件**：6连涨 vs 6涨1跌，哪个更准确？

### 💡 容忍版显示逻辑

**重要**：容忍版（带 `t` 后缀）文件**仅显示原版中没有的股票**

- **原版**：显示所有符合条件的股票（如 10 只）
- **容忍版**：仅显示新增股票（如 5 只），原版已有的不重复显示
- **优点**：避免重复，更直观地看到容忍版的增量价值

**示例**：
- `xuanxue_134_6`：10 只股票（A, B, C, D, E, F, G, H, I, J）
- `xuanxue_134_6t`：5 只新增股票（K, L, M, N, O）- 不包含原版已有的 10 只

详细说明请查看：[容忍版显示说明.md](./容忍版显示说明.md)

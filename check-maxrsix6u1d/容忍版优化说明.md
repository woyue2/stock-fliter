## 🔧 技术实现

### 修改文件
`combiners/xuanxue_combiner.py`

### 核心逻辑
```python
# 如果是容忍版（带t后缀），则排除原版中已有的股票
if strategy_name.endswith('t'):
    # 找到对应的原版策略名（去掉t后缀）
    original_strategy_name = strategy_name[:-1]
    if original_strategy_name in results:
        original_candidates = results[original_strategy_name]
        # 排除原版中已有的股票
        original_codes = set(original_code_series.astype(str))
        mask = ~code_series.astype(str).isin(original_codes)
        candidates = candidates[mask].copy()
```

## ❓ 常见问题

### Q1: 如何查看容忍版的全部股票（包含原版已有的）？

**方法1**：查看趋势分析详情文件
```bash
trend_rules_detail_20260131_123456.csv
```
- 包含所有股票的所有指标（原版 + 容忍版）

**方法2**：合并两个文件
- 原版文件 + 容忍版文件 = 容忍版全部股票

### Q2: 为什么容忍版新增数量可能为 0？

**原因**：
- 容忍版捕捉到的股票，原版全部都有
- 说明在当前市场环境下，两个版本结果一致

**建议**：
- 这种情况下，优先使用原版结果
- 原版更严格，质量更高

### Q3: 容忍版新增的股票质量如何？

**特点**：
- 允许小跌（< 1.64%）
- 可能因为小幅震荡被原版过滤
- 仍然符合其他所有条件（MAxRSIx6U1D、趋势分析、网格测试）

**建议**：
- 结合具体股票分析
- 查看最近几天的K线图
- 判断小跌是否为正常回调

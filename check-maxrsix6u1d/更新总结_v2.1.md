## 🔍 技术细节

### 小跌阈值：1.64%

**为什么是1.64%？**
- 基于统计学的 1σ（一个标准差）原则
- 在正态分布中，约68%的数据落在 ±1σ 范围内
- 可以过滤掉大部分噪音波动

**如何调整？**
修改 `mystic_indicators_tolerant.py`：
```python
DEFAULT_SMALL_DROP_THRESHOLD = 1.64  # 改为你想要的值
```

### 有效上涨的判断

```python
def is_effective_up(open_price, close_price, threshold=1.64):
    if close >= open:
        return True  # 真涨或平
    else:
        drop_pct = (open - close) / open * 100
        if drop_pct < threshold:
            return True  # 小跌，视为有效上涨
        else:
            return False  # 大跌
```

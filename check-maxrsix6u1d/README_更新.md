## 🎯 28种组合策略

### 命名规则
```
xuanxue_{组合代号}_{玄学条件}{版本后缀}

组合代号: 134, 13, 3, 34, 14, 1, 4
玄学条件: 6 (连续6涨), 61 (10天6涨1跌)
版本后缀: 无 (原版), t (容忍版)
```

### 示例
- `xuanxue_134_6` - 1+3+4组合 + 连续6阳（原版）
- `xuanxue_134_6t` - 1+3+4组合 + 连续6有效涨（容忍版）
- `xuanxue_3_61` - 仅趋势 + 10天6涨1跌（原版）
- `xuanxue_3_61t` - 仅趋势 + 10天6有效涨1真跌（容忍版）

# 6阳1阴动力学说明文档

## 概述

本系统提供了**两套6U1D指标**，供用户对比观察：

1. **原版指标**（严格版）：要求严格的连续阳线
2. **模糊版指标**（Tolerant）：允许小幅回调（跌幅 < 1.64%）

## 一、原版6U1D指标（严格版）

### 核心概念
- **阳线**：收盘价 > 开盘价
- **阴线**：收盘价 < 开盘价
- **连续6阳**：连续6天都是阳线，不允许任何阴线

### 指标列表

| 指标英文名 | 指标中文名 | 说明 |
|-----------|-----------|------|
| `pattern_6u1d_10d` | 6U1D_10天内有6连阳后1阴 | 在最近10天内，存在连续6天阳线后紧跟1天阴线的模式 |
| `pattern_6u` | 6U1D_最近6天连续阳线 | 最近6天全部是阳线 |
| `pattern_today_down_after_6up` | 6U1D_今天阴线且前6天连阳(回调) | 今天是阴线，且前6天连续阳线（**买入机会**） |
| `pattern_today_is_6th_up` | 6U1D_今天是第6天阳线(等待) | 今天是第6天连续阳线（**等待回调**） |
| `pattern_6up_prev_down` | 6U1D_6连阳前一天是阴线 | 6连阳之前那天是阴线（底部启动信号） |

### 使用场景
- 适合寻找**强势连续上涨**的股票
- 严格筛选，结果数量较少但质量较高
- 适合保守型投资者

## 二、模糊版6U1D指标（Tolerant）

### 核心概念
- **有效上涨**：阳线 OR 小跌（跌幅 < 1.64%）
- **真跌**：跌幅 >= 1.64% 的阴线
- **连续6有效涨**：连续6天都是"有效上涨"（可包含小跌）

### 为什么是 1.64%？
- 基于统计学的**1σ（一个标准差）**原则
- 在正态分布中，约68%的数据落在 ±1σ 范围内
- 1.64% 是一个经验阈值，可以过滤掉大部分噪音波动

### 指标列表

| 指标英文名 | 指标中文名 | 说明 |
|-----------|-----------|------|
| `pattern_6u1d_10d_tolerant` | 6U1D_10天内有6连涨后1跌(模糊模式) | 在最近10天内，存在连续6天有效涨后紧跟1天真跌的模式 |
| `pattern_6u_tolerant` | 6U1D_最近6天连续涨(模糊模式) | 最近6天全部是有效上涨（可含小跌） |
| `pattern_today_small_drop_after_6up` | 6U1D_今天小跌且前6天连涨(买入机会) | 今天小跌，且前6天有效连涨（**买入机会**） |
| `pattern_today_is_6th_up_tolerant` | 6U1D_今天是第6天涨(等待) | 今天是第6天有效涨（**等待回调**） |
| `pattern_6up_prev_down_tolerant` | 6U1D_6连涨前一天是真跌 | 6有效连涨之前那天是真跌（底部启动信号） |

### 使用场景
- 适合寻找**稳健上涨但允许小幅震荡**的股票
- 筛选结果更多，覆盖面更广
- 适合积极型投资者

### 示例对比

#### 原版（严格）
```
Day1: 涨 → Day2: 涨 → Day3: 涨 → Day4: 涨 → Day5: 涨 → Day6: 涨 ✅
Day1: 涨 → Day2: 涨 → Day3: 跌(-1.2%) → Day4: 涨 → Day5: 涨 → Day6: 涨 ❌
```

#### 模糊版
```
Day1: 涨 → Day2: 涨 → Day3: 涨 → Day4: 涨 → Day5: 涨 → Day6: 涨 ✅
Day1: 涨 → Day2: 涨 → Day3: 跌(-1.2%) → Day4: 涨 → Day5: 涨 → Day6: 涨 ✅（小跌可忽略）
Day1: 涨 → Day2: 涨 → Day3: 跌(-2.5%) → Day4: 涨 → Day5: 涨 → Day6: 涨 ❌（大跌不可忽略）
```

## 四、优先级标签说明

系统会自动为每只股票标注优先级：

### 原版优先级
- **[STAR]买入**：今天阴线且前6天连阳（6连阳后的回调，最佳买入时机）
- **[STAR]等待**：今天是第6天阳线（等待明天回调再买入）
- **◆连阳**：最近6天连续阳线
- **○模式**：10天内有6连阳模式

### 模糊版优先级
- **[STAR]买入-小回调**：今天小跌且前6天连涨（6连涨后的小回调，最佳买入时机）
- **[STAR]等待-连涨中**：今天是第6天有效涨（等待回调）
- **◆连涨中**：最近6天有效连涨
- **○模式**：10天内有6连涨模式

## 五、使用建议

### 1. 如何选择版本？

**选择原版（严格版）如果你：**
- 偏好强势连续上涨的股票
- 希望减少假信号
- 愿意接受较少的候选股票
- 追求高质量而非高数量

**选择模糊版如果你：**
- 认为小幅震荡是正常的
- 希望获得更多候选股票
- 愿意接受一定的波动
- 追求更广的覆盖面

### 2. 如何对比观察？

建议同时运行两个版本，对比结果：

```bash
# 运行完整分析（会生成所有28种组合）
python main.py
```

然后对比：
- **原版 vs 模糊版**：哪个版本的命中率更高？
- **不同组合**：134、13、3、34、14、1、4 哪个组合效果最好？
- **不同6U1D条件**：6连涨 vs 6涨1跌，哪个更准确？

### 3. 回测验证

建议对历史数据进行回测：
1. 选择一个历史日期（如1个月前）
2. 运行分析，获取候选股票
3. 观察这些股票在之后1个月的表现
4. 统计胜率、平均收益等指标
5. 对比原版和模糊版的效果

### 4. 参数调整

如果你想调整"小跌阈值"（默认1.64%），可以修改：

```python
# 在 pattern_indicators_tolerant.py 中
DEFAULT_SMALL_DROP_THRESHOLD = 1.64  # 改为你想要的值，如 2.0
```

**原版报告**：

**模糊版报告（仅显示新增股票）**：

  - 包含对比说明（新增数量、原版已有数量、总数量）
  - **仅显示模糊版相比原版额外捕捉到的股票**
  - 更直观地看到模糊版的增量价值

### 汇总报告
- `trend_rules_detail_YYYYMMDD_HHMMSS.csv`：所有股票的趋势分析详情

- `pattern_candidates_YYYYMMDD_HHMMSS.csv`：满足任一6U1D条件的股票

### 💡 模糊版文件说明

**为什么模糊版只显示新增股票？**

1. **避免重复**：原版已有的股票不需要重复查看
2. **更直观**：直接看到模糊版的增量价值
3. **节省时间**：快速定位到模糊版独有的机会

**示例**：
- 原版 `xuanxue_134_6`：10只股票（A, B, C, D, E, F, G, H, I, J）
- 模糊版总共：15只股票（A, B, C, D, E, F, G, H, I, J, K, L, M, N, O）
- 模糊版文件 `xuanxue_134_6t`：仅显示5只新增股票（K, L, M, N, O）

**如何查看模糊版全部股票？**

如果需要查看模糊版的全部股票（包含原版已有的），可以：
1. 查看 `trend_rules_detail_YYYYMMDD_HHMMSS.csv`（包含所有股票的所有指标）
2. 或者临时注释掉排除逻辑（修改 `xuanxue_combiner.py`）

## 七、常见问题

### Q1: 为什么模糊版的结果更多？
A: 因为模糊版允许小跌（< 1.64%），所以能捕捉到更多"稳健上涨但有小幅震荡"的股票。

### Q2: 两个版本哪个更准确？
A: 需要通过回测验证。一般来说：
- 原版：精准度高，但覆盖面窄
- 模糊版：覆盖面广，但可能有更多噪音

### Q3: 如何理解"买入机会"和"等待"？
A: 
- **买入机会**：6连涨后出现回调，是低吸的好时机
- **等待**：正在6连涨中，建议等待回调再买入（避免追高）

### Q4: 可以只运行某几个组合吗？
A: 可以，修改 `xuanxue_combiner.py` 中的 `COMBINATIONS` 列表，注释掉不需要的组合。

### Q5: 如何调整小跌阈值？
A: 修改 `pattern_indicators_tolerant.py` 中的 `DEFAULT_SMALL_DROP_THRESHOLD` 常量。

## 八、技术细节

### 有效上涨的判断逻辑

```python
def is_effective_up(open_price, close_price, threshold=1.64):
    if close >= open:
        return True  # 真涨或平
    else:
        drop_pct = (open - close) / open * 100
        if drop_pct < threshold:
            return True  # 小跌，视为有效上涨
        else:
            return False  # 大跌
```

### 连续6有效涨的判断

```python
# 检查最近6天是否全部为"有效上涨"
effective_up_series = [is_effective_up(o, c) for o, c in zip(opens[-6:], closes[-6:])]
is_6_consecutive_up = all(effective_up_series)
```

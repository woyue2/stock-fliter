# 神奇数字（盘口语言）规则与通达信实现

这是主力资金用来传递操盘信号的“密码”，主要用于判断股票的见顶（卖出）和见底（买入）信号。

## 一、 核心应用前提
1. **特定位置有效**：必须出现在日K线的**最高价**（见顶信号，跑路）或**最低价**（见底信号，买入）。
2. **实时监控**：在交易日盘中，关注实时最低价是否触碰这些神奇数字。

## 二、 神奇数字分类
| 分类 | 示例 | 逻辑说明 |
| :--- | :--- | :--- |
| **完全相同** | 11.11, 5.55 | AAAA 或 AAA |
| **三位相同** | 11.18, 22.33 | AAAB 或 ABBB (注:22.33亦属对子) |
| **对子/对称** | 12.12, 12.21, 5.15 | ABAB, ABBA, ABA |
| **双对子** | 11.22, 9.988 | AABB |
| **顺子数** | 5.67, 7.65 | ABC 连号（不限顺序） |
| **相差一** | 12.13, 16.15 | ABAC (整数同，小数连号) |
| **尾数相同** | 73.55, 50.66 | 小数后两位相同 (CC) |
| **整数/零** | 28.20, 14.70 | 尾数为 0 |
| **数学运算** | 6.32 (2*3=6) | 满足乘除、加减或求和等于10/20 |

## 三、 通达信条件选股公式 (SQSZ)
### V1 (精简修正版：纯神奇数字 + 逻辑穷尽)
此版本仅筛选神奇数字，**不限价格位置**（取消了月内最低限制）。
逻辑已全面升级：支持**任意整十数求和**，并**穷尽了一位数/两位数/三位数带两位小数**的所有加法和乘法组合逻辑。

```pascal
{ 1. 基础数字拆解 }
PL := ROUND2(L, 2); { 针对当日下影线最低点 }
{ 提取各数字位，不足的位默认为0 }
D0 := MOD(INTPART(PL/100), 10);  { 百位 (三位数股票) }
D1 := MOD(INTPART(PL/10), 10);   { 十位 (两位数股票) }
D2 := MOD(INTPART(PL), 10);      { 个位 }
D3 := MOD(INTPART(PL*10), 10);   { 十分位 }
D4 := MOD(INTPART(PL*100), 10);  { 百分位 }

{ ===== 2. 基础形态判断 (对子/顺子/相同数) ===== }
{ 四位基础形态 (如11.22, 12.13)，要求股价 >= 10 }
BASE_4BIT := PL>=10 AND (
    (D1=D2 AND D2=D3 AND D3=D4) OR { AAAA }
    (D1=D2 AND D3=D4) OR           { AABB }
    (D1=D3 AND D2=D4) OR           { ABAB }
    (D1=D4 AND D2=D3) OR           { ABBA }
    (D1=D3 AND ABS(D2-D4)=1)       { ABAC }
);

{ 三位基础形态及尾数规律 (适用于所有股价) }
BASE_3BIT := 
    (D2=D3 AND D3=D4) OR           { AAA }
    (D2=D4) OR                     { ABA }
    (D3=D4) OR                     { CC  }
    (D4=0) OR                      { 尾数0 }
    ((D2=D3-1 AND D3=D4-1) OR (D2=D3+1 AND D3=D4+1)); { 顺子 }

{ ===== 3. 数学运算组合穷举 ===== }
{ A. 一位数带两位小数运算 (关注 D2, D3, D4) }
MATH_1BIT := 
    { -- 加法穷举 -- }
    (D2+D3=D4 OR D2+D4=D3 OR D3+D4=D2) OR
    { -- 乘法穷举 (排除全0情况) -- }
    ((D2*D3=D4 OR D2*D4=D3 OR D3*D4=D2) AND PL>=1) OR
    { -- 求和定值为任意整十数 -- }
    (MOD(D2+D3+D4, 10)=0 AND (D2+D3+D4)>0);

{ B. 两位数带两位小数运算 (关注 D1, D2, D3, D4) }
MATH_2BIT := PL>=10 AND (
    { -- 四位数任意求和定值 -- }
    (MOD(D1+D2+D3+D4, 10)=0 AND (D1+D2+D3+D4)>0) OR
    { -- 两两相加对称 -- }
    (D1+D2 = D3+D4) OR (D1+D4 = D2+D3) OR (D1+D3 = D2+D4) OR
    { -- 三加一等于第四数 -- }
    (D1+D2+D3=D4 OR D1+D2+D4=D3 OR D1+D3+D4=D2 OR D2+D3+D4=D1) OR
    { -- 乘法组合扩展 -- }
    (D1*D2 = D3*D4 AND PL>=1)
);

{ C. 三位数带两位小数运算 (关注 D0, D1, D2, D3, D4，百元股特有规律) }
MATH_3BIT := PL>=100 AND (
    { -- 五数求和为任意整十数 -- }
    (MOD(D0+D1+D2+D3+D4, 10)=0 AND (D0+D1+D2+D3+D4)>0)
);

{ D. 整数部分与小数位运算 (关注 INTPART, D3, D4，如 13.94: 13=9+4) }
INT_MATH := INTPART(PL) = (D3+D4) OR INTPART(PL) = (D3*D4);

{ 4. 汇总判定 }
SQ_ALL := BASE_4BIT OR BASE_3BIT OR MATH_1BIT OR MATH_2BIT OR MATH_3BIT OR INT_MATH;

{ 最终选股输出 }
SQSZ: SQ_ALL;
```

> [!TIP]
> **关于 L 的说明**：
> *   在 K 线图中，`L` 永远指向下影线的最低点。
> *   公式中的 `SQSZ` 在执行选股时，会去检查每一只股票当天的 `L` 是否满足 `G1~G13` 中的任意一个。

> [!TIP]
> **使用方法**：
> 1. 打开通达信 -> `Ctrl+F` (公式管理器) -> `条件选股公式` -> `其他类型` -> `新建`。
> 2. 名称填写 `SQSZ`，将上述代码粘贴进去（确保中间变量是 `:=`）。
> 3. 点击 `确认` 保存。
> 4. 使用 `Ctrl+T` (条件选股) 调出该公式，即可实时筛选出最低价满足规则的股票。

### V2 (修正版：增加30日最低价 + 逻辑穷尽)
在 V1 的全穷尽数学逻辑基础上，增加了**30日内最低价**的硬性条件。筛选出的必须是带有阶段性见底信号的神奇数字。

```pascal
{ 1. 基础数字拆解 }
PL := ROUND2(L, 2); { 核心：针对下影线最低点 }
D0 := MOD(INTPART(PL/100), 10);  { 百位 }
D1 := MOD(INTPART(PL/10), 10);   { 十位 }
D2 := MOD(INTPART(PL), 10);      { 个位 }
D3 := MOD(INTPART(PL*10), 10);   { 十分位 }
D4 := MOD(INTPART(PL*100), 10);  { 百分位 }

{ 2. 形态与运算整合逻辑 }
BASE_4BIT := PL>=10 AND ((D1=D2 AND D2=D3 AND D3=D4) OR (D1=D2 AND D3=D4) OR (D1=D3 AND D2=D4) OR (D1=D4 AND D2=D3) OR (D1=D3 AND ABS(D2-D4)=1));
BASE_3BIT := (D2=D3 AND D3=D4) OR (D2=D4) OR (D3=D4) OR (D4=0) OR ((D2=D3-1 AND D3=D4-1) OR (D2=D3+1 AND D3=D4+1));

MATH_1BIT := (D2+D3=D4 OR D2+D4=D3 OR D3+D4=D2) OR ((D2*D3=D4 OR D2*D4=D3 OR D3*D4=D2) AND PL>=1) OR (MOD(D2+D3+D4, 10)=0 AND (D2+D3+D4)>0);
MATH_2BIT := PL>=10 AND ((MOD(D1+D2+D3+D4, 10)=0 AND (D1+D2+D3+D4)>0) OR (D1+D2 = D3+D4) OR (D1+D4 = D2+D3) OR (D1+D3 = D2+D4) OR (D1+D2+D3=D4 OR D1+D2+D4=D3 OR D1+D3+D4=D2 OR D2+D3+D4=D1) OR (D1*D2=D3*D4 AND PL>=1));
MATH_3BIT := PL>=100 AND (MOD(D0+D1+D2+D3+D4, 10)=0 AND (D0+D1+D2+D3+D4)>0);

INT_MATH := INTPART(PL) = (D3+D4) OR INTPART(PL) = (D3*D4);
SQ_ALL := BASE_4BIT OR BASE_3BIT OR MATH_1BIT OR MATH_2BIT OR MATH_3BIT OR INT_MATH;

{ 3. 核心限制：今日最低价是30日内最低点 }
LOW_30 := L = LLV(L, 30);

{ 最终选股输出 }
SQSZ: SQ_ALL AND LOW_30;
```

# Minute Pattern Analyzer - 使用文档

## 📖 概述

**Minute Pattern Analyzer** 是一个基于**240维向量分析**的股票走势形态识别工具。

### 核心思想

```
一天的交易 = 240分钟 → 240维向量 → 形态识别
```

将每只股票的日内K线分成240份（每分钟一个采样点），把每分钟的采样当成一个变量，组成一个240维向量，用这个向量来判定股票走向。

### 优势

- **微观细节**：捕捉每分钟的走势变化
- **完整信息**：保留日内价格演变的完整过程
- **量化对比**：可以使用向量相似度进行比较
- **早盘vs午盘**：精确对比上下半场表现

### 3. fetch_minute_akshare.py - 获取真实分钟数据

**功能**：使用 AkShare 获取实时分钟级股票数据

**参数**：

| 参数 | 说明 | 示例 |
|------|------|------|
| `--code, -c` | 单只股票代码 | `--code 600519` |
| `--codes` | 多只股票（逗号分隔） | `--codes 600519,000001` |
| `--all` | 全市场扫描 | `--all` |
| `--sample N` | 随机采样N只 | `--sample 10` |
| `--realtime` | 获取实时分钟数据 | `--realtime` |
| `--days N` | 获取天数 | `--days 5` |

**示例**：

```bash
# 获取单只股票分钟数据
cd ~/Park/stock-fliter/get-data
python fetch_minute_akshare.py --code 600519 --realtime

# 获取多只股票
python fetch_minute_akshare.py --codes 600519,000001,600036 --realtime

# 全市场采样10只
python fetch_minute_akshare.py --all --sample 10 --realtime
```

### 4. minute_pattern_analyzer.py - 核心分析器

**功能**：240维向量形态分析引擎（供其他脚本调用）

**支持的形态**：

| 形态代码 | 形态名称 | 特征 |
|----------|----------|------|
| `strong_uptrend` | 单边上涨 | 持续上涨，收盘高于开盘 |
| `strong_downtrend` | 单边下跌 | 持续下跌，收盘低于开盘 |
| `v_reversal` | V型反转 | 先跌后涨，午后拉升 |
| `inverted_v` | 倒V型 | 先涨后跌，午后回落 |
| `high_open_low_close` | 高开低走 | 开盘冲高后持续走低 |
| `low_open_high_close` | 低开高走 | 开盘下跌后持续走高 |
| `consolidation` | 震荡整理 | 波动较大但无明显趋势 |
| `flat` | 平淡走势 | 波动较小，方向不明 |

## ⚠️ 注意事项

1. **分钟数据来源**：
   - AkShare 实时数据：最准确，但需要在线获取
   - 日K估算：离线可用，精度略低

2. **数据量要求**：
   - 最佳：48条以上（完整的交易日）
   - 最低：10条以上（可分析，但不精确）

3. **市场范围**：
   - 支持所有A股（上海/深圳）
   - 代码格式：`600519` 或 `000001`

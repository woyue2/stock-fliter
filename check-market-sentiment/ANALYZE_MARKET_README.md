# 📊 股票走势形态分析 - 通用脚本

## 🎯 功能说明

这是一个通用的股票走势形态分析脚本，可以分析任意日期的股票走势，识别8种经典形态，并生成详细的分析报告。

### 识别的形态
1. ✅ **高开低走型** - 先上升再下降，整体往下走
2. ✅ **低开高走型** - 先下降再上升，整体往上走
3. ✅ **V型反转** - 低开后强势反弹
4. ✅ **倒V型** - 高开后大幅回落
5. ✅ **单边上涨** - 持续走强
6. ✅ **单边下跌** - 持续走弱
7. ✅ **震荡整理** - 上下波动
8. ✅ **平淡走势** - 几乎无波动

### 新增功能
- 📊 **早盘vs午盘分析** - 分析早盘和午盘价格高低
- 📈 **市场情绪指数** - 量化市场强弱
- 🎨 **美观的HTML报告** - 可视化展示分析结果

## 📈 技术指标说明

### 基础指标
1. **开盘涨跌幅** = (开盘价 - 昨收) / 昨收 × 100%
2. **日内涨跌幅** = (收盘价 - 开盘价) / 开盘价 × 100%
3. **全天涨跌幅** = (收盘价 - 昨收) / 昨收 × 100%
4. **振幅** = (最高价 - 最低价) / 昨收 × 100%

### 形态指标
5. **上影线比例** = (最高价 - max(开盘,收盘)) / (最高价 - 最低价) × 100%
6. **下影线比例** = (min(开盘,收盘) - 最低价) / (最高价 - 最低价) × 100%
7. **实体比例** = |收盘价 - 开盘价| / (最高价 - 最低价) × 100%

### 早午盘指标 🆕
8. **早盘特征价格** = 开盘价 × 0.7 + 最高价 × 0.3
9. **午盘特征价格** = 收盘价 × 0.7 + 最低价 × 0.3
10. **早午盘差异** = (早盘价格 - 午盘价格) / 昨收 × 100%

### 市场情绪指数
```
市场情绪指数 = (强势形态数 - 弱势形态数) / 总股票数 × 100
```
- 强势形态：低开高走、V型反转、单边上涨
- 弱势形态：高开低走、倒V型、单边下跌
- 指数范围：-100（极度弱势）到 +100（极度强势）

## 📝 数据要求

### 必需的数据结构
```
get-data/data/
├── stocks_index/
│   ├── 2026-01-30/
│   │   └── stocks_index.csv  (股票列表)
│   └── 2025-05-05/
│       └── stocks_index.csv
└── raw/
    ├── 600011.csv  (股票价格数据)
    ├── 600012.csv
    └── ...
```

### stocks_index.csv 格式
必须包含以下列：
- `代码` 或 `code`: 股票代码
- `名称` 或 `name`: 股票名称（可选）

### raw/*.csv 格式
必须包含以下列：
- `date` 或 `日期`: 日期
- `open` 或 `开盘`: 开盘价
- `close` 或 `收盘`: 收盘价
- `high` 或 `最高`: 最高价
- `low` 或 `最低`: 最低价

## ⚠️ 注意事项

1. **需要前一日数据**
   - 分析某一天需要有前一天的收盘价
   - 如果是假期后第一天，可能无法分析

2. **数据完整性**
   - 确保 raw 目录中有对应股票的数据文件
   - 数据文件中要包含目标日期的数据

3. **性能考虑**
   - 分析2000+股票约需30-60秒
   - 建议在数据量大时耐心等待

## 💬 常见问题

**Q: 为什么提示"没有有效数据"？**
A: 可能是目标日期没有前一日的收盘价数据。尝试分析其他日期。

**Q: 可以分析多个日期吗？**
A: 可以多次运行脚本，每次指定不同的日期。

**Q: HTML报告可以分享吗？**
A: 可以！HTML文件是独立的，可以直接发送给他人用浏览器打开。

**Q: 如何导出所有股票的数据？**
A: CSV文件包含所有股票的完整数据，可以用Excel打开。

**Q: 早盘vs午盘的判断准确吗？**
A: 这是基于日线数据的近似计算，实际早午盘价格需要分钟级数据。但这个方法可以反映大致趋势。

# 市场情绪分析 - 高开低走统计

## 📊 功能说明

分析整个市场的高开低走情况，评估市场情绪和恐慌程度。

## 🎯 核心指标

### 1. 高开低走的定义

**基本条件：**
- 开盘价 > 昨日收盘价（高开）
- 收盘价 < 开盘价（低走）

**强度分级：**
- **轻度**：收盘价 > 昨收（假阳线，虽然回落但仍收红）
- **中度**：收盘价 < 昨收，但不在最低区域
- **重度**：收盘价接近最低价（下影线很短，收盘在下方30%区域）

### 2. 🆕 分时特征分析

通过K线形态推断分时走势，判断是早盘还是午盘高开低走：

**早盘型：**
- 💀 **早盘冲高秒杀**：开盘即顶，全天暴跌（最危险）
- 📉 **早盘冲高回落**：开盘即顶，但有支撑

**午盘型：**
- ⚠️ **午盘冲高杀跌**：盘中诱多后暴跌（危险）
- 📊 **午盘冲高回落**：盘中冲高后回落，但有支撑

**全天型：**
- 🔻 **全天弱势下行**：全天承压，尾盘杀跌
- 💚 **震荡回落有支撑**：虽然回落但有抄底
- 📉 **震荡下行**：普通震荡下行

**判断逻辑：**
```python
# 通过最高价相对开盘价的位置判断
if 最高价接近开盘价:
    → 早盘冲高回落型（开盘即顶）
elif 最高价远离开盘价:
    → 午盘冲高杀跌型（盘中诱多）
else:
    → 全天震荡下行型
```

### 3. 关键指标

```python
高开幅度 = (开盘价 - 昨收) / 昨收 × 100%
回落幅度 = (开盘价 - 收盘价) / 开盘价 × 100%
净涨跌幅 = (收盘价 - 昨收) / 昨收 × 100%
```

### 4. 市场情绪指数（0-100分）

综合评分，越高表示市场越恐慌：

**计算公式：**
- 高开低走比例得分（0-40分）：高开低走股票数 / 总股票数
- 平均回落幅度得分（0-30分）：平均回落幅度 × 3
- 重度占比得分（0-30分）：重度高开低走占比 × 30

**评级标准：**
- 😊 0-15分：健康
- 😐 15-30分：中性偏弱
- 😟 30-50分：谨慎
- 😰 50-70分：恐慌
- 😱 70-100分：极度恐慌

## 💡 应用场景

### 1. 市场情绪判断

- **情绪指数 > 50**：市场恐慌，可能是抄底机会
- **情绪指数 30-50**：市场谨慎，观望为主
- **情绪指数 < 30**：市场健康，正常波动

### 2. 分时特征应用

**早盘冲高秒杀占比高（>15%）：**
- 说明：开盘即顶，主力出货明显
- 策略：避免追高，等待回调

**午盘冲高杀跌占比高（>15%）：**
- 说明：盘中诱多，多头溃败
- 策略：最危险信号，空仓观望

**震荡回落有支撑占比高（>25%）：**
- 说明：虽有回落但有抄底资金
- 策略：可逢低布局

### 3. 交易策略

- **重度高开低走占比高**：主力出货明显，避免追高
- **轻度高开低走为主**：正常获利回吐，可逢低布局
- **高开低走比例 > 30%**：市场分歧大，谨慎操作

### 4. 结合其他指标

- 配合大盘指数走势
- 结合成交量变化
- 观察行业分布（未来版本）

## 🔧 技术实现

### 核心算法

```python
# 判断高开低走
is_gap_up_pullback = (open > prev_close) and (close < open)

# 强度分类
if close > prev_close:
    category = "轻度"  # 假阳线
elif (close - low) / (high - low) < 0.3:
    category = "重度"  # 收盘接近最低
else:
    category = "中度"

# 🆕 分时特征判断
high_from_open = (high - open) / (high - low)
close_from_low = (close - low) / (high - low)

if high_from_open < 0.2:  # 最高价接近开盘
    if close_from_low < 0.3:
        pattern = "早盘冲高秒杀"
    else:
        pattern = "早盘冲高回落"
elif high_from_open > 0.3:  # 盘中有冲高
    if close_from_low < 0.3:
        pattern = "午盘冲高杀跌"
    else:
        pattern = "午盘冲高回落"
else:
    pattern = "震荡下行"
```

## 🤔 常见问题

**Q: 为什么有些股票没有被统计？**
A: 可能是数据不足（上市时间短）或数据加载失败。

**Q: 情绪指数多少算正常？**
A: 通常15-30分是正常范围，超过50分需要警惕。

**Q: 轻度高开低走也算恐慌吗？**
A: 不算，轻度是正常的获利回吐，重度才是真正的恐慌性抛售。

**Q: 如何区分早盘和午盘高开低走？**
A: 通过K线形态判断：
- 最高价接近开盘价 → 早盘冲高回落
- 最高价远离开盘价 → 午盘冲高杀跌
- 收盘接近最低价 → 全天弱势

**Q: 哪种分时特征最危险？**
A: 早盘冲高秒杀和午盘冲高杀跌最危险，说明主力出货坚决。

# 经典走势形态实验

## 📊 实验目的

识别和分析股票市场中的几种经典走势形态，特别是：
- **先上升再下降，整体往下走** - 高开低走型
- **先下降再上升，整体往上走** - 低开高走型
- 以及其他经典形态

## 🎯 识别的形态类型

### 1. 高开低走型
**特征**：开盘 > 昨收，收盘 < 开盘
- 先上升再下降，整体往下走
- 可能表示市场抛压较重，多头力量不足
- 典型场景：利好消息开盘冲高，但随后获利盘涌出

**识别条件**：
```
开盘涨跌幅 > 0.5%  且  日内涨跌幅 < -0.5%
```

### 2. 低开高走型
**特征**：开盘 < 昨收，收盘 > 开盘
- 先下降再上升，整体往上走
- 可能表示市场买盘积极，空头力量减弱
- 典型场景：利空消息开盘低开，但随后抄底盘涌入

**识别条件**：
```
开盘涨跌幅 < -0.5%  且  日内涨跌幅 > 0.5%
```

### 3. V型反转
**特征**：低开后强势反弹
- 开盘低，日内涨幅大，下影线长
- 表示市场在低位获得强力支撑
- 典型场景：恐慌性抛售后快速反弹

**识别条件**：
```
开盘涨跌幅 < -0.5%  且  日内涨跌幅 > 1.0%  且  下影线 > 30%
```

### 4. 倒V型
**特征**：高开后大幅回落
- 开盘高，日内跌幅大，上影线长
- 表示市场在高位遇到强力阻力
- 典型场景：冲高后遭遇大量抛盘

**识别条件**：
```
开盘涨跌幅 > 0.5%  且  日内涨跌幅 < -1.0%  且  上影线 > 30%
```

### 5. 单边上涨
**特征**：开盘涨且日内继续涨
- 持续走强，实体较大
- 表示市场多头力量强劲
- 典型场景：重大利好持续发酵

**识别条件**：
```
开盘涨跌幅 > 0.5%  且  日内涨跌幅 > 0.5%  且  实体比例 > 50%
```

### 6. 单边下跌
**特征**：开盘跌且日内继续跌
- 持续走弱，实体较大
- 表示市场空头力量强劲
- 典型场景：重大利空持续发酵

**识别条件**：
```
开盘涨跌幅 < -0.5%  且  日内涨跌幅 < -0.5%  且  实体比例 > 50%
```

### 7. 震荡整理
**特征**：上下波动，收盘接近开盘
- 振幅较大，但实体较小
- 表示市场多空力量均衡
- 典型场景：等待方向选择

**识别条件**：
```
振幅 > 2.0%  且  |日内涨跌幅| < 0.5%  且  实体比例 < 30%
```

### 8. 平淡走势
**特征**：几乎无波动
- 振幅很小
- 表示市场交投清淡，观望情绪浓厚

**识别条件**：
```
振幅 < 2.0%
```

## 📈 关键指标说明

### 1. 开盘涨跌幅
```
开盘涨跌幅 = (开盘价 - 昨日收盘价) / 昨日收盘价 × 100%
```
- 正值：高开
- 负值：低开

### 2. 日内涨跌幅
```
日内涨跌幅 = (收盘价 - 开盘价) / 开盘价 × 100%
```
- 正值：收盘高于开盘（走高）
- 负值：收盘低于开盘（走低）

### 3. 全天涨跌幅
```
全天涨跌幅 = (收盘价 - 昨日收盘价) / 昨日收盘价 × 100%
```

### 4. 振幅
```
振幅 = (最高价 - 最低价) / 昨日收盘价 × 100%
```

### 5. 上影线比例
```
上影线比例 = (最高价 - max(开盘价, 收盘价)) / (最高价 - 最低价) × 100%
```
- 上影线长：冲高后回落明显

### 6. 下影线比例
```
下影线比例 = (min(开盘价, 收盘价) - 最低价) / (最高价 - 最低价) × 100%
```
- 下影线长：探底后反弹明显

### 7. 实体比例
```
实体比例 = |收盘价 - 开盘价| / (最高价 - 最低价) × 100%
```
- 实体大：单边走势明显
- 实体小：震荡走势

### 8. 市场情绪指数
```
市场情绪指数 = (强势形态数 - 弱势形态数) / 总股票数 × 100
```
- 正值：市场偏强
- 负值：市场偏弱
- 范围：-100 到 +100

## 🚀 使用方法

### 运行完整实验
```bash
cd check-market-sentiment
python experiment_patterns.py
```

### 实验内容

实验脚本会依次运行5个实验：

#### 实验1：基础形态识别
- 加载最新交易日数据
- 识别所有股票的形态
- 生成统计报告

#### 实验2：各形态的典型案例
- 展示每种形态的典型案例
- 显示详细的技术指标
- 帮助理解各形态的特征

#### 实验3：市场情绪分析
- 分析最近5个交易日的市场情绪
- 追踪情绪指数的变化趋势
- 识别市场强弱转换

#### 实验4：极端形态识别
- 找出最强的高开低走（冲高回落最厉害）
- 找出最强的低开高走（探底反弹最厉害）
- 找出最强的V型反转和倒V型
- 找出最强的单边上涨和下跌

#### 实验5：导出详细结果
- 导出CSV数据文件
- 导出文本统计报告
- 生成美观的HTML可视化报告

## 📁 输出文件

所有输出文件保存在 `output/` 目录：

### 1. CSV数据文件
```
pattern_analysis_YYYYMMDD_HHMMSS.csv
```
包含所有股票的详细数据和形态识别结果

### 2. 文本报告
```
pattern_report_YYYYMMDD_HHMMSS.txt
```
包含统计摘要和形态分布

### 3. HTML可视化报告
```
pattern_analysis_YYYYMMDD_HHMMSS.html
```

包含：
- 市场概览卡片
- 形态分布图表
- 典型案例TOP5
- 详细数据表格（前100条）

## 🔧 单独使用模块

### 使用形态分析器
```python
from data_loader import MarketDataLoader
from pattern_analyzer import PatternAnalyzer

# 加载数据
loader = MarketDataLoader("../get-data/data/stocks_index")
market_data = loader.load_recent_days(1)
market_data = loader.calculate_previous_close(market_data)

# 分析形态
analyzer = PatternAnalyzer()
result = analyzer.analyze_market(market_data)

# 查看结果
print(result['sentiment_index'])  # 市场情绪指数
print(result['pattern_counts'])   # 各形态数量
```

```python
# 生成报告
reporter = PatternHTMLReporter("output")
html_file = reporter.generate_report(result)
print(f"报告已生成: {html_file}")
```

## 📊 实战案例

### 案例1：识别高开低走
某股票数据：
- 昨日收盘：10.00元
- 今日开盘：10.50元（+5.0%，高开）
- 今日收盘：10.20元（-2.86%，低走）
- 全天涨跌：+2.0%

**分析**：
- 开盘涨跌幅：+5.0% > 0.5% ✓
- 日内涨跌幅：-2.86% < -0.5% ✓
- **识别为：高开低走型**
- **含义**：先上升再下降，整体往下走，虽然全天仍上涨2%，但日内走势偏弱

### 案例2：识别低开高走
某股票数据：
- 昨日收盘：10.00元
- 今日开盘：9.50元（-5.0%，低开）
- 今日收盘：9.80元（+3.16%，高走）
- 全天涨跌：-2.0%

**分析**：
- 开盘涨跌幅：-5.0% < -0.5% ✓
- 日内涨跌幅：+3.16% > 0.5% ✓
- **识别为：低开高走型**
- **含义**：先下降再上升，整体往上走，虽然全天仍下跌2%，但日内走势偏强

### 案例3：识别V型反转
某股票数据：
- 昨日收盘：10.00元
- 今日开盘：9.50元（-5.0%，低开）
- 今日最低：9.30元（-7.0%）
- 今日收盘：10.20元（+7.37%，强势反弹）
- 下影线比例：45%

**分析**：
- 开盘涨跌幅：-5.0% < -0.5% ✓
- 日内涨跌幅：+7.37% > 1.0% ✓
- 下影线比例：45% > 30% ✓
- **识别为：V型反转**
- **含义**：低开后探底，随后强势反弹，形成V型走势

## 💡 技术细节

### 形态识别算法
1. 计算关键指标（开盘涨跌、日内涨跌、振幅等）
2. 按优先级匹配形态规则
3. 优先识别极端形态（V型、倒V型）
4. 其次识别方向性形态（高开低走、低开高走）
5. 最后识别震荡和平淡形态

### 数据处理流程
```
stocks_index/*.csv (股票列表)
    ↓
raw/*.csv (价格数据)
    ↓
计算前一日收盘价
    ↓
计算技术指标
    ↓
形态识别
    ↓
统计分析
    ↓
生成报告
```

## 📝 注意事项

1. **数据要求**
   - 需要有前一日收盘价才能计算开盘涨跌幅
   - 数据必须包含：open, close, high, low

2. **阈值调整**
   - 可以在 `PatternAnalyzer` 类中调整识别阈值
   - 默认阈值：开盘/日内涨跌 ±0.5%，振幅 2.0%

3. **性能考虑**
   - 分析5000+股票约需15秒
   - 建议使用最近几天的数据进行实验

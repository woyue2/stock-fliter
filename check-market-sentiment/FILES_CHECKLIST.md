## ✨ 特别说明

### 关于"先上升再下降"和"先下降再上升"

这两种形态的识别逻辑：

**高开低走型（先上升再下降）**
```
昨收 10.00 → 开盘 10.50 (+5%) ← 先上升
开盘 10.50 → 收盘 10.20 (-2.86%) ← 再下降
整体：相对开盘往下走
```

**低开高走型（先下降再上升）**
```
昨收 10.00 → 开盘 9.50 (-5%) ← 先下降
开盘 9.50 → 收盘 9.80 (+3.16%) ← 再上升
整体：相对开盘往上走
```

这两种形态已经成功识别并通过测试！✅

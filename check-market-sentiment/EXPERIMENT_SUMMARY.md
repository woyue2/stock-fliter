### 2. 识别的形态类型

| 形态 | 特征 | 市场含义 | 测试状态 |
|------|------|----------|----------|
| **高开低走型** | 开盘>昨收，收盘<开盘 | 先上升再下降，整体往下走 | ✅ 通过 |
| **低开高走型** | 开盘<昨收，收盘>开盘 | 先下降再上升，整体往上走 | ✅ 通过 |
| **V型反转** | 低开+强反弹+长下影线 | 探底后强势反弹 | ⚠️ 需要明显下影线 |
| **倒V型** | 高开+大幅回落+长上影线 | 冲高后大幅回落 | ✅ 通过 |
| **单边上涨** | 开盘涨+日内继续涨 | 持续走强 | ✅ 通过 |
| **单边下跌** | 开盘跌+日内继续跌 | 持续走弱 | ✅ 通过 |
| **震荡整理** | 振幅大+实体小 | 多空均衡 | ✅ 正常 |
| **平淡走势** | 振幅很小 | 交投清淡 | ✅ 正常 |

### 3. 关键技术指标

1. **开盘涨跌幅** = (开盘 - 昨收) / 昨收 × 100%
2. **日内涨跌幅** = (收盘 - 开盘) / 开盘 × 100%
3. **全天涨跌幅** = (收盘 - 昨收) / 昨收 × 100%
4. **振幅** = (最高 - 最低) / 昨收 × 100%
5. **上影线比例** = (最高 - max(开盘,收盘)) / (最高 - 最低) × 100%
6. **下影线比例** = (min(开盘,收盘) - 最低) / (最高 - 最低) × 100%
7. **实体比例** = |收盘 - 开盘| / (最高 - 最低) × 100%

### 4. 市场情绪指数

```
市场情绪指数 = (强势形态数 - 弱势形态数) / 总股票数 × 100
```

- **强势形态**：低开高走、V型反转、单边上涨
- **弱势形态**：高开低走、倒V型、单边下跌
- **指数范围**：-100（极度弱势）到 +100（极度强势）

## 🔧 技术细节

### 形态识别优先级
1. **极端形态优先**：V型反转、倒V型
2. **单边形态次之**：单边上涨、单边下跌
3. **方向性形态**：高开低走、低开高走
4. **震荡形态最后**：震荡整理、平淡走势

### 识别阈值（可调整）
```python
THRESHOLD_OPEN = 0.5      # 开盘涨跌幅阈值 (%)
THRESHOLD_INTRADAY = 0.5  # 日内涨跌幅阈值 (%)
THRESHOLD_AMPLITUDE = 2.0 # 振幅阈值 (%)
```

### 数据处理流程
```
stocks_index/*.csv (股票列表)
    ↓
raw/*.csv (价格数据)
    ↓
计算前一日收盘价 (groupby + shift)
    ↓
计算7个技术指标
    ↓
形态识别（按优先级匹配）
    ↓
统计分析（市场情绪指数）
    ↓
生成报告（CSV + TXT + HTML）
```

## 📝 注意事项

### 1. V型反转识别
- 需要明显的下影线（>30%）
- 如果下影线不够明显，会识别为"低开高走型"
- 这是合理的，因为V型反转是更极端的形态

### 2. 数据要求
- 必须有前一日收盘价（用于计算开盘涨跌幅）
- 必须有完整的OHLC数据（开高低收）
- 数据加载时会自动过滤无效记录

### 3. 性能考虑
- 分析5000+股票约需15秒
- 建议使用最近几天的数据进行实验
- HTML报告只显示前100条详细数据

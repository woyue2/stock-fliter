# 卖出决策分析工具使用说明

## 📁 文件说明

本文件夹包含两个股票卖出分析脚本：

### 1. sell_analyzer.py - 快速分析工具
**用途**：快速判断是否应该卖出股票

**特点**：
- 使用 Softmax 融合 6 个技术指标
- 给出明确的卖出概率
- 提供"持有/卖出"操作建议
- 支持 3 种交易模式（保守/标准/激进）

**输出示例**：
```
卖出概率: 78.3%
操作建议: 建议卖出 / 减仓至50%以下
风险等级: 🟠 高风险
```

### 2. deep_analyzer.py - 深度分析工具
**用途**：全面分析股票技术面

**特点**：
- 7 大维度深度分析
- 震荡 vs 趋势判断
- MACD 历史追踪
- 顶背离/底背离检测
- 量价关系分析
- 综合风险评估

**输出示例**：
```
一、均线系统分析
二、MACD分析
三、震荡vs趋势判断
四、成交量分析
五、顶背离/底背离检测
六、RSI与KDJ分析
七、综合总结
```

## 📊 技术指标说明

### sell_analyzer.py 使用的技术指标

1. **均线死叉**（权重：2.0）
   - MA5 下穿 MA20
   - 跌破 MA60

2. **MACD**（权重：1.8）
   - DIF 死叉 DEA
   - 柱状图由红转绿

3. **RSI 超买**（权重：1.5）
   - RSI > 70（超买）
   - 顶背离

4. **KDJ**（权重：1.3）
   - 高位死叉（K>80）
   - 超买

5. **布林带**（权重：1.2）
   - 触及上轨
   - 开口放大

6. **量价关系**（权重：1.6）
   - 放量下跌
   - 价涨量缩

### deep_analyzer.py 的分析维度

1. **均线系统分析**
   - 多头/空头排列
   - 死叉/金叉检测
   - 均线斜率

2. **MACD 分析**
   - 10 日历史追踪
   - 绿柱持续时间
   - 死叉/金叉

3. **震荡 vs 趋势**
   - 价格区间
   - 波动率分析
   - 方向判断

4. **成交量分析**
   - 量比计算
   - 量价关系
   - 放量/缩量判断

5. **背离检测**
   - 顶背离（价格新高但指标未新高）
   - 底背离（价格新低但指标未新低）

6. **RSI 与 KDJ**
   - 超买超卖
   - 死叉金叉
   - 高低位判断

7. **综合总结**
   - 风险信号统计
   - 操作建议
   - 关键点位

## ⚙️ 交易模式说明

### sell_analyzer.py 的 3 种模式

#### 1. 保守模式
- 温度参数：0.5
- 特点：只在信号非常明确时才建议卖出
- 适用：长期投资者、稳健型
- 阈值：卖出概率 > 80% 才建议卖

#### 2. 标准模式（推荐）
- 温度参数：1.0
- 特点：平衡型
- 适用：大多数投资者
- 阈值：卖出概率 > 70% 建议卖

#### 3. 激进模式
- 温度参数：2.0
- 特点：稍有风险就建议卖出
- 适用：短线交易者、激进型
- 阈值：卖出概率 > 55% 就建议卖

## 🔧 常见问题

### Q1: 为什么两个工具的结论不一致？

**A**: 这是因为分析维度不同：
- `sell_analyzer.py` 看的是综合得分
- `deep_analyzer.py` 提供详细信息供你判断

**建议**：以深度分析的结论为准，结合你自己的判断。

### Q2: 卖出概率 100% 是什么意思？

**A**: 表示技术面发出强烈卖出信号，但不保证一定跌。

**建议**：至少减仓 50% 以上，不要满仓。

### Q3: 震荡行情怎么操作？

**A**:
- 区间下沿：低吸
- 区间上沿：高抛
- 不要追涨杀跌
- 严格止损

### Q4: 如何判断是震荡还是趋势？

**A**: 使用 `deep_analyzer.py`，它会明确告诉你：
```
震荡信号: 3, 趋势信号: 1
结论: ✅ 震荡行情
```

### Q5: 技术指标失效怎么办？

**A**:
1. 看多个指标（不要只看一个）
2. 结合成交量
3. 参考大盘走势
4. 关注基本面消息
